# 项目长期记忆

## 笔记组织约定

### 诞视·趋势研习营系列
- **每篇独立成篇**（type: course），不再用聚合 column 文件混放。萨哥明确要求"笔记不要混到一起"。
- 文件命名按主题，如 `26年4月政治局会议解读.md`、`26年7月政治局会议解读.md`
- frontmatter 用 `source` 字段标注来源（如 `诞视·趋势研习营 2606期 NO.015（2026-08-05发布）`），不再用 `instructor/platform/started/finished` 这类聚合字段
- 关联部分用"同系列：[[其他篇]]"互链，已拆出的独立研究用"独立成篇：[[文件名]]"
- 独立成篇格式参照 `英伟达投资Marvell战略拆解.md`：frontmatter(type:course/created/source) → 基本信息(表格) → 关联 → 分割线 → # 内容标题 → ## 章节
- 来源课程在关联里用**纯文字**"诞视·趋势研习营 2606期"，不用 wiki 链接（聚合文件已不存在）

### 课程笔记通用
- 协作流程见 CLAUDE.md：用户分享内容/观点 → 与 Claude 讨论 → 整理写入对应主题二级标题；"我的思考"类主观内容讨论后再补
- **写作规范**（萨哥要求）：中文不夹杂英文，必要英文用括号注释中文译词；首次出现的人名/专有名词加简略注释

### 万维钢《现代思维工具》笔记译名约定
- Power-Seeking Theorems 译为"**选项保留定理**"（非万维钢原文的"能耐寻求定理"）
- 理由：望文生义、贴合定理本质（保留未来选项而非主动追求权力）；"寻求"误导（定理是结构性结论而非主动行为）
- 笔记文件：`3-Resources/课程笔记/思维工具/现代思维工具-成长战略.md`
