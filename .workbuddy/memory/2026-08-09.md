## web-access skill 修复（跨项目可复用）

- 修复 `scripts/cdp-proxy.mjs` fallback 分支 bug：手动 `--remote-debugging-port=9222` 启动 Chrome 时，`wsPath` 返回 null 导致用不带 id 的 `/devtools/browser`，被 Chrome 136+ 拒绝（non-101）
- 修复方式：fallback 时 fetch `/json/version` 取 `webSocketDebuggerUrl` 的 pathname 作为 wsPath
- 手动启动临时 Chrome 连接 CDP 的可行参数：`--remote-debugging-port=9222 --remote-allow-origins=* --user-data-dir=<临时profile>`（独立于用户日常浏览器，不干扰）
- Windows 下 `pkill`/`taskkill //PID` 不可靠，改用 PowerShell `Stop-Process -Id <PID> -Force` 杀旧 proxy
