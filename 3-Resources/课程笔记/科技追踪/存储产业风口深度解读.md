# 课程内容

## 第7季·第8期 存储产业风口深度解读（2026-07-09）

> **主线**：存储是 AI 产业链中的**跟随者而非头部**——它没有英伟达那样的垄断定价权，但因 AI 推理爆发带来产能稀缺，享有数年红利期。核心逻辑是"看懂 AI 才能看懂存储"：只要 AI Token 消耗维持指数增长，存储需求（HBM→DRAM→NAND→HDD 逐级释放）就会延续。本轮不是传统的 2-3 年去库存短周期，而是技术革命大爆发带来的长周期；但阶段性的关键企业预期已被充分定价，未来将呈现"好业绩 + 大波动"叠加，需警惕 2029 年产业与金融风险共振。

### 核心结论（直播六要点）

1. **理解存储产业必须看懂 AI**，只要 AI Token 爆发不停，产业趋势还将延续
2. **工程调优下 AI 红利逐层释放**，HBM、DRAM、NAND、HDD 需求逐级释放中
3. **技术与产业格局下，HBM 需求仍然强劲**，DRAM、NAND 短缺正在显现
4. **现阶段关键企业未来预期已较为充分**，产业发展会呈现好业绩与大波动叠加
5. **关注 2027 年的产能是否如期落地**，注意更上游的 CoWoS 封装瓶颈
6. **警惕 2029 年的产业与金融风险叠加**，提前做好规划和防范

### 名词速查

| 缩写 | 全称 | 说明 |
|------|------|------|
| HBM | High Bandwidth Memory | 高带宽内存。把多层 DRAM 芯片堆叠，贴近 GPU 封装，为 GPU 高速并行计算提供高速数据支持 |
| DRAM | Dynamic Random Access Memory | 动态随机存取存储器，电脑/手机内存，服务器运行程序的临时内存 |
| NAND | NAND Flash | 闪存，断电后仍能保存数据的非易失性存储，固态硬盘（SSD）和手机存储的元器件 |
| HDD | Hard Disk Drive | 机械硬盘，高速磁头读写的大容量存储，成熟产品，成本低容量大 |
| KV Cache | Key-Value Cache | 把多轮对话中不变的内容存入缓存，避免重复计算，降低算力消耗 |
| CMX | Context Memory Storage | 上下文内存存储，英伟达 2026 年推出的技术，允许 GPU 从 HBM 向更慢存储卸载 KV Cache |
| CoWoS | Chip on Wafer on Substrate | 台积电 2.5D/3D 先进封装技术，HBM 必须通过它与 GPU/ASIC 整合 |

## 第一部分：AI 推理爆发引动存储需求爆发

### 一、存储产业的定位：跟随者而非头部

- **存储不是 AI 产业链的头部**。王煜全一贯强调"潮流产业的头部企业"——AI 是潮流产业，头部是英伟达；存储是其中的**跟随者**，不是头部。
- **为什么还要关注存储**：因为现在稀缺。稀缺不是因为供不上，而是扩产能跟不上释放，这个时间差就是红利期。未来还有两三年、三四年的周期。
- **存储的壁垒比芯片低**：原因是没有差异化。GPU 当年也有很多家做，但只有英伟达靠 CUDA 建立壁垒；现在英伟达靠**万卡集群能力**（计算能力的产能输出）延续垄断。存储没有这种垄断性，所以拿不到超额利润。
- **商业逻辑**：潮流产业保证产业有巨大增长；头部企业保证饼做大后有分饼的权利。存储迄今为止没有分饼能力，它的红利来自产能稀缺的**时长**，而非定价权。

### 二、传统存储周期 vs 本轮 AI 驱动的爆发

#### 传统周期：去库存循环

- 传统存储周期本质是**去库存**：需求由消费电子终端驱动，呈现明显的"补产能→过剩→去库存"周期性波动，以前基本**两三年一个周期**。
- 每轮周期常有新技术加入（磁盘→闪存 NAND→HBM），产生新增市场并吃掉部分老市场，形成周期性现象。
- 过去每轮周期**涨一两年就见顶**：因为高利润驱动扩产，一两年后产能扩起来，就不可能高利润了。
- 计算平台范式转变创造动力：新计算设备 = 设备量↑ × 新旧方案切换（1993 Windows PC 超级周期、2010 智能手机&云、2017-2018 云存储周期）。但以往每轮在 1-2 年内见顶。

#### 本轮爆发：AI 推理创造的本质需求

- **本轮不是周期性规律，而是技术革命大爆发**。以前的缓慢上升是 IT 逐渐普及；现在是人工智能的迅速扩散，逻辑完全不同。
- **高利润期会特别长**：产能会在很长时间供不上货。以前一两年，这次好几年。
- **扩产谨慎带来紧缺持续**：存储厂商过去二三十年形成了极其谨慎的扩产习惯（扩不好就赔钱），即使被告知"这回是革命"，掏钱扩产的依然谨慎 → 紧缺持续更长时间。
- **达里奥观点**：人一辈子只经历过一次的事，不可能看懂。现在赶上的是技术革命大爆发（服务规模化 / 数字革命），相当于工业革命级的大事，要求站到更大的视角看问题。

#### 本轮爆发的三个叠加因素

1. **AIGC 内容爆发**：存储需求增加
2. **推理侧由 Agent 驱动的爆发**：智能体出来后要求更多推理，结构改变造成存储需求大幅增长
3. **大量自研芯片 + 多级缓存**：英伟达提出多级缓存（既省钱又提升效率），对内存需求有明确拉动

### 三、KV Cache 与 CMX：上下文内存存储

> 这是理解本轮 HBM 需求爆发的关键技术逻辑。

- **问题背景**：AI 进入多轮次、长上下文阶段。Agent 互动时，每次交互都要调出以前的内容，交互次数增多 → 上下文越来越长 → 计算速度/效率下降。
- **KV Cache 解法**：把以前对话的不变内容不反复计算，存入内存（尤其高带宽缓存），下次只提供新增内容。**把重复的计算转化为存储**，显著降低算力消耗。
- **代价**：需要大量高带宽缓存（离算力最近的缓存部分）。
- **CMX（上下文内存存储）**：英伟达 2026 年推出，允许 GPU 从 HBM 向更慢的存储空间（如高速 SSD）卸载 KV Cache，在推理时实现多 GPU、大上下文处理。形成"高带宽缓存 → DRAM → NAND → HDD"逐层下降的内存层级机制。
- **关键认知**：**内存层级是英伟达定义的**。你在某一层里技术再领先，也不能跨层使用——你只是"产业新增/产业增强"，不是产业头部。除非长期稀缺或长期性能领先，否则吃不到长期红利。
- **铠侠跟随**：铠侠在 2026 投资者日强调 KV cache 是关键瓶颈，推出与 CMX 框架兼容的高带宽 SSD CM 系列，预测 AI 推理细分市场存储需求 CAGR 高达 86%。

#### 讨论补充：KV Cache 技术原理与模型/硬件厂商工程边界

**Transformer 推理与自注意力机制**：大模型生成文字是一个 token 一个 token 往后续的（自回归生成）。每生成一个新 token，它需要"回头看"之前所有 token，计算关联度。这个过程中每个 token 产生三个向量：Q（Query，查询）、K（Key，钥匙）、V（Value，值）。注意力计算 = 用新 token 的 Q 跟所有历史 token 的 K 算关联度，再用关联度加权历史 token 的 V。

**KV Cache 的本质**：把已经算过的历史 token 的 K 和 V 向量缓存下来，不重复计算。生成新 token 时直接从缓存读取历史 K/V，只算新 token 自己的部分追加进缓存。

**"变与不变"的界线**：
- **不变 = 历史 token 的 K/V**：token 一旦生成，内容固定，K/V 向量也固定。每生成新 token 都要调用它们，但它们永远不变——之前每次重算就是纯浪费。这部分"不变的计算"被转化为"存储"。
- **变 = 正在生成的新 token 的 K/V**：每一步都是新的，必须真算。
- **本质：空间换时间**。用内存存历史 K/V，换算力消耗下降。代价是缓存随序列长度线性膨胀，尤其 Agent 多轮交互时膨胀非常快，而这些缓存最理想的存放位置是紧贴 GPU 的 HBM（需高频读取）——**这就是 AI 推理引爆 HBM 需求的技术根源**。

**CMX 多级存储层级**：KV Cache 的矛盾在于——它最想存在 HBM（快），但 HBM 容量有限且贵。Agent 多轮交互让 KV Cache 越来越大，很快超出 GPU 内部 HBM 容量。CMX 的解法：允许 GPU 把 KV Cache 从 HBM 卸载到更慢但更大的存储层级，形成 "HBM → DRAM → NAND/SSD → HDD" 的多级存储链。越往下越慢但容量越大、越便宜。铠侠 CM 系列就是接住从 HBM/DRAM 溢出的 KV Cache 的兼容 SSD。

**模型厂商 vs 硬件厂商的工程实践边界**：

| 维度 | 模型厂商（Kimi、Google） | 硬件厂商（英伟达） |
|------|--------------------------|---------------------|
| 优化层面 | 算法/软件层面 | 硬件架构层面 |
| 典型实践 | PagedAttention（分页管理减少碎片）、混合精度量化（FP8/INT8 压缩 KV Cache）、稀疏注意力、淘汰策略 | CMX 多级存储架构、HBM 堆叠设计、GPU 与存储调度 |
| 做的事 | 在既定硬件能力下更高效地"使用"内存 | 定义内存层级规则，提供存储调度"能力" |
| 改变什么 | 不改变硬件架构，只优化软件使用方式 | 定义硬件架构规则和存储层级 |
| 类比 | 程序员优化代码，让程序在同一台电脑上跑更快 | 电脑厂商重新设计主板和内存架构 |

**边界核心**：模型厂商决定 KV Cache 怎么存、怎么压缩、怎么淘汰，但不能改变"HBM→DRAM→SSD"这条层级结构本身——那是英伟达定的。Kimi/Google 分享的是"软件层面如何更聪明地管理 KV Cache"，天花板是硬件架构设的。英伟达的 CMX 是"定义硬件架构规则"，结构性、不可被软件替代。用王煜全的话说：英伟达掌握**产业控制权**（S 级，画格子的人），模型厂商的软件优化是**产业增强**（在格子里跳得更巧的人）。关注存储投资时，看英伟达定义的架构规则比看模型厂商的软件优化更重要——前者决定"蛋糕怎么分"，后者只是"在既定蛋糕上切得更巧"。

**逻辑链总结**：Agent 多轮交互 → 长上下文 → KV Cache 膨胀 → HBM 首选但装不下 → CMX 多级卸载 → 各级存储需求逐层引爆。

**CAGR（Compound Annual Growth Rate，复合年增长率）**：把"几年翻了 N 倍"换算回"等价于每年匀速涨百分之多少"的滚雪球增长率。不是简单平均（加法思维），而是复利（乘法思维）——每年增长建立在上一年的基础上，越滚越大。举例：1 亿的需求按 86% CAGR 增长 → 第 1 年 1.86 亿、第 2 年 3.46 亿、第 3 年 6.44 亿、第 4 年 11.98 亿、第 5 年 22.3 亿——5 年翻 22 倍。对比：若每年固定加 0.86 亿（线性），5 年后只有 5.3 亿，差了 4 倍多。铠侠说"AI 推理存储需求 CAGR 86%"意味着需求以爆炸速度膨胀（滚雪球），不是线性增长——这正是存储厂商即使谨慎扩产也跟不上的原因。

### 四、产业时点规律：Cerebras 与氢能源的类比

- **核心规律**：一个产业当主流技术已实现产业化时，资源会倾斜过去，竞争性产业的产业化就没有机会了。不是技术不好，是**晚了**。
- **氢能源 vs 电动车**：氢燃料电池若在电动车产业化之前突破就有机会；现在电池已产业化，氢能源的产业化瓶颈没人帮解决。
- **Cerebras**：技术很好，但在英伟达靠 CUDA 打天下时没形成生态；现在英伟达已进入万卡集群整体计算中心布局，Cerebras 只是一个板子，没戏了。
- **投资启示**：科技投资要看运气/信命——不是自己能决定的，要看竞争对手的产业化实践。你没毛病，只是晚于竞争对手，也会完蛋。

#### 讨论补充：Cerebras 详解与产业化难度 vs 技术难度

**Cerebras 详解**：
- Cerebras Systems，美国 AI 芯片公司，2015 年成立，创始人 Andrew Feldman。
- 招牌技术：WSE（Wafer-Scale Engine，晶圆级引擎）——不把晶圆切成很多小芯片，而是把整块晶圆做成一颗超大芯片。WSE-3（2024 年）约 4 万亿晶体管、90 万核心，单芯片面积比英伟达最大 GPU 大几十倍。
- 逻辑：与其用很多小 GPU 组集群、忍受芯片间通信瓶颈，不如做一颗超大芯片让通信瓶颈消失。
- 结果：技术很漂亮但没有形成生态——英伟达已靠 CUDA 软件生态 + 万卡集群完成产业化，Cerebras 没有 CUDA 那样的软件生态，别人用它的芯片得从零适配，没人愿意。在英伟达已进入整体计算中心布局后，Cerebras"就是一个板子，没戏了"。

**技术难度 vs 产业化难度**：

| 维度 | 技术难度 | 产业化难度 |
|------|----------|------------|
| 问的是什么 | 这个技术本身有多难实现、多复杂 | 把它做成产品、规模生产、形成生态、被市场接受有多难 |
| 谁来评判 | 工程师（能不能做出来） | 市场（有没有人愿意用、有没有人帮你配套） |
| 关键问题 | "做不做得出来" | "做出来有没有人跟你" |

**两个对照案例**：
- **氢能源 vs 电动车**：氢燃料电池技术从第一性原理看更领先（能量密度高、清洁），但电池先一步产业化，资源全倾斜过去。氢能源的瓶颈（存储运输等）工业界本可解决，但没人帮解决——因为产业化时机错过了。不是技术不好，是产业化晚了。
- **Cerebras vs 英伟达**：Cerebras 晶圆级芯片技术确实厉害，但英伟达已靠 CUDA + 万卡集群完成产业化。Cerebras 没有软件生态，没人围绕它建配套——不是技术不好，是产业化晚了。

**投资启示**：技术难度高 ≠ 有投资价值，产业化难度才是真正卡人的地方。产业化的核心不是技术本身，而是"有没有一帮人愿意围绕你建生态"。科技投资要看运气——你能决定自己的产业化速度，但决定不了竞争对手比你快。你没毛病，只是晚于竞争对手，也会完蛋。

## 第二部分：需求爆发后的产业格局

### 一、存储寡头格局与 HBM 挤出效应

#### 供给高度集中

- 存储供给已高度集中化：**SK 海力士、三星、美光三家占 DRAM 市场 91%**，长鑫位列第四（不到 10%）。
- 多年产业周期淘汰，存储上游原厂仅剩 3-5 家。下游需求爆发时，产能难以快速扩张——因为垄断了，扩产能只能靠它扩。

#### HBM 挤出效应

- **HBM 显著吞噬 DRAM 晶圆产能**：HBM 的晶圆也是 DRAM 的晶圆。因为 HBM 更赚钱，晶圆更多用来生产 HBM 而非传统内存。
- **原厂产能转向**：海力士、三星、美光主动放弃中低端，专供数据中心高端。→ 中低端存储也供不应求（不是低端本身供不应求，而是高端把低端产能挤掉了）。
- **给中国的机会**：别人都生产 HBM 去了，中低端留给中国。长鑫在 DRAM 已进入规模量产阶段，但 HBM 刚进入初步量产，与龙头相差一代以上。
- **江波龙案例**：净利暴涨 743 倍，但靠的是提前囤积存储芯片赚价格暴涨红利（2020-2024 存货从 22.46 亿增至 78.33 亿）。仍未改变其作为主控厂商集成开发的产业位置，没有原厂定价权。

#### 讨论补充：HBM 挤出效应、模组厂定位与存储类型

**HBM 挤出效应（面包厂比喻）**：一个面包厂每天只有 100 袋面粉。以前 30 袋做高档面包（贵）、70 袋做普通面包；现在高档面包需求暴涨利润暴增，80 袋都做高档面包 → 普通面包只剩 20 袋面粉 → 普通面包也短缺了。这就是"挤出"——高档把普通的产能挤掉了。普通面包短缺不是因为普通面包需求大，而是面粉被高档面包抢走了。HBM 和普通 DRAM 用的是同一种"面粉"（DRAM 晶圆），HBM 太赚钱，原厂把晶圆优先做 HBM，留给普通 DRAM 的产能就少了 → 普通 DRAM 也短缺。再往下传：原厂全做 HBM 放弃中低端 NAND → 中低端 NAND 也短缺。**存储短缺是从高端往中低端逐级挤出的，不是各层独立短缺。**

**存储产业链与模组厂定位**：

| 层级 | 角色 | 代表公司 | 生态位 |
|------|------|----------|--------|
| 晶圆厂 | 生产硅晶圆（原材料） | 台积电等 | — |
| 存储原厂 | 把晶圆切成颗粒，造 DRAM/NAND/HBM | 三星/海力士/美光/铠侠 | S 级 |
| 模组厂/独立存储厂 | 买颗粒+主控+PCB，组装成品 | 金士顿/江波龙 | B 级 |
| 消费者/企业 | 买到成品 | — | — |

模组厂既不是纯经销商（经销商只倒手不加工），也不是原厂（不造颗粒）。他们是**中间加工组装**一道：从原厂买来裸颗粒，加上主控芯片、焊到 PCB 板上、套上外壳，做成消费者能直接用的成品（U 盘、内存条、SSD）。

- **金士顿**：全球最大独立存储厂，但未上市。从三星/美光/海力士买 NAND 颗粒，自己加主控和外壳组装成 U 盘/内存条/SSD。不造一颗芯片，但出货量全球最大。B 级（系统集成层），没有原厂定价权。
- **江波龙**：A 股上市模组厂，主要做嵌入式存储（eMMC/UFS，贴在手机里）、SSD、内存条，面向企业（B 端）。个人消费者很少直接买"江波龙"牌产品，但手机里的存储可能是江波龙组装的模组。净利暴涨 743 倍是提前囤货赚差价，没改变 B 级模组厂位置。

**NAND 成品形态分类**：NAND 是"面粉"，U 盘/手机存储/SSD 是用面粉做的不同"面包"——底层都是 NAND 闪存，只是封装形态不同：

| 成品形态 | 用在哪 | 底层 |
|----------|--------|------|
| U 盘 | 便携存储 | NAND |
| 手机存储（eMMC/UFS） | 手机/平板 | NAND |
| SSD 固态硬盘 | 电脑/服务器 | NAND |
| 机械硬盘 HDD | 大容量存储 | 磁盘（非 NAND） |

手机 8G+64G = 8G **DRAM**（运行内存，临时存储，断电就没）+ 64G **NAND**（存储空间，存照片/APP/数据，断电还在）。一快一慢、一个临时一个持久。

### 二、存储厂商的谨慎扩产与长期协议锁定

- **极度谨慎的扩产习惯**：过去二三十年，扩产能周期基本一两年，一旦过了周期再扩就赔本。存储厂商形成非常谨慎的扩产习惯。
- **长期协议锁定**：因为需求太大但厂商不敢扩产，客户被迫接受苛刻条件——长期锁定（多年每年买多少、按什么价格）、不可取消、预付定金，甚至 SK 海力士正在谈判**取消价格上限**。
- **现状**：美光/SK 海力士/三星 2026 产能全部售罄，2027 年协议锁定中。2026 存储厂商登上全球 TOP50。

### 三、需求前瞻：CapEx 规划定义下限

#### 讨论补充：CapEx 与 OpEx 的区别

**CapEx（Capital Expenditure，资本支出）** vs **OpEx（运营支出）** 是一对：

餐厅比喻——开一家餐厅：CapEx = 买/装修店面、买厨房设备、买桌椅（一次性大笔投入，买能用很久的固定资产）；OpEx = 每天买菜、发工资、交水电费（日常持续花销）。

AI 数据中心同理：CapEx = 建机房、买服务器、买 GPU、买 HBM（一次性砸大钱买硬件）；OpEx = 电费、运维人员工资、网络费（日常运营花销）。

**"CapEx 规划定义存储需求下限"**：各大云厂商已经规划好未来要砸多少钱建 AI 算力设施，这些钱里有一部分是必须买 HBM/存储的——钱已经定了要花，对应的存储需求就是"保底"的（需求下限）。反过来，如果 Token 需求增长比 CapEx 规划还猛，现有 CapEx 就不够用，存储缺口更大。

#### 中美芯片 CapEx 差距

| 口径 | 2026 年 | 2027 年 |
|------|---------|---------|
| 全球（主要美国） | 7000 亿美元 | 1 万亿美元 |
| 中国 | 1000 亿美元 | 1200 亿美元 |

- 差着约 10 倍。中国的数字可能有水分（假设英伟达不对中国限制，大量购买）。
- 英伟达对中国断供是关键变量：去年中国买了 400 万块芯片，其中 240 万块是美国人的（多数英伟达），160 万块是中国人的（80 多万华为、40 多万平头哥）。

#### 1GW 数据中心的成本结构

- 运营支出（OPEX）：约 9 亿美元（接近 10 亿）
- 资本支出（CAPEX）：约 70 亿，其中：
  - 基础设施约 13 亿
  - 网络设施约 11 亿
  - **买服务器约 50 亿**（占 70%-80%）
- 服务器占年化开支约 **66%**
- **HBM 占 AI 芯片组件成本 63%**（Q4 2025），但在 B200 中降到 45%（因为算力要提升，其他部分要省钱，零部件占比尽量小）

#### 现有 CapEx 下 HBM 仍然短缺

- 即使维持看得见的资本支出，高带宽缓存依然短缺——需求长期存在。
- Meta 租算力给别人的真相：算力建设是阶梯性的（建一个中心涨一块），需求是线性增长的。刚建成时供大于求，临时租出去，一两年后又供不应求。是"建多了"不是"囤多了"。
- 2025 年各大 IT 公司基建投资超过自身利润（以前都小于利润）→ 它们是第一波见红利的受益者，知道需求增长迅速。

### 四、Token 经济决定需求上限

- **Token 消耗维持指数增长**：OpenRouter 数据显示按月计算的 Token 消耗量明显上涨，无下降趋势。一年时间从 1T 涨到 30T-40T（约 20 倍）。
- **紧平衡测算**：勉勉强强够使的情况下，Token 消耗增长倍数：

> **什么是"紧平衡"**：紧巴巴地刚好够用——供给和需求勉强匹配，没有任何余量，稍有波动就可能不够。餐厅比喻：一家餐厅刚好 50 个座位，来了 50 个客人刚好坐满，但再多 1 个就没座了。在课程里"紧平衡"是一个**乐观假设的下限**——假设 Token 需求和算力供给刚好勉强匹配的最理想情况。但现实是 Token 一年涨了 20 倍，连"紧巴巴刚好够"都做不到，说明缺口巨大。

| 区间 | 紧平衡下 Token 消耗增长倍数 |
|------|---------------------------|
| 2026 → 2027 | 约 4-6x |
| 2027 → 2028 | 约 1.6-2.9x |
| 2028 → 2029 | 约 1.6-2.1x |
| 2029 → 2030 | 约 1.2-1.5x |
| 2030 → 2031 | 约 1.1-1.3x |

- **关键判断**：现有 CapEx 规划支持 2031 年 AI 算力增长 30 倍以内。但今年一年就涨了 20 倍，紧平衡都做不到——空缺巨大。当全网推理 Token 消耗量保持指数增长，对应存储层级将出现系统性短缺，这是判断存储需求拐点的核心量化指标。
- **HBM 短缺会持续多久**：供给侧约束（先进制程扩产周期长、长协锁定优质供给）+ 需求侧加速（AI 推理规模持续扩张、CapEx 上调带动采购）。预计到 2030-2031 年也只是接近满足，而非充分满足。

## 第三部分：看懂热门企业的产业生态位

### 一、生态位分级（S/A/B/C/D 五级）

> 核心认知：不要只看概念。技术难度与产业结构是两个东西——在没有控制力的环节掌握核心技术，依然拿不到最大收益。必须在潮流产业链的头部（有控制力）才行。

| 等级 | 名称 | 定义 | 代表公司 |
|------|------|------|----------|
| **S 级** | 核心定价层 | 决定产能、价格、技术路线，有客户长协和定价权 | 三星、SK 海力士、美光、铠侠、SanDisk、希捷、西部数据、长鑫、长江存储 |
| **A 级** | 核心配套层 | 没有它核心产品难以交付，但不直接定价全行业 | ASML、应用材料、泛林、东京电子、KLA、爱德万测试、泰瑞达、Marvell、群联、慧荣 |
| **B 级** | 系统集成层 | 受益于出货量，但议价权取决于客户和认证 | 戴尔、HPE、联想、浪潮、华为、NetApp、Pure Storage、江波龙、金士顿 |
| **C 级** | 周边配套层 | 产品真实重要，但价值占比低，依赖客户给机会 | 滑轨、机柜、液冷、铜管、连接器、线束、结构件 |
| **D 级** | 外围概念层 | 收入占比低、客户认证弱、只是蹭概念 | 泛 AI、泛数据中心、泛新材料 |

- **C 级的微妙**：例如机柜铰链，因占总成本低且强调"别出事"，利润可以很高，但完全没有说服力——对方一句话决定生死，取决于对方是否善良。

### 二、代表企业透支程度分析

> 三个维度判断好公司：① 级别高（有定价权）② PE 相对低（价格合算）③ 未来增长大（有空间）

| 公司 | 业务类型 | P/E (TTM) | 透支程度 | 要点 |
|------|----------|-----------|----------|------|
| **美光 Micron** | 原厂 IDM | ~21-22x | 低-中 | 均衡型，服务器 DRAM 是压舱石，产业链内透支最低之一 |
| **SK 海力士** | 原厂 IDM | 21-24x | 中 | 严重受 AI 算力增长影响，放缓下 HBM 先过剩 |
| **三星 Samsung** | 原厂 IDM 综合 | 50x | 低 | 弹性弱，多元化分散风险也分散爆发收益（手机业务摊薄） |
| 铠侠 Kioxia | 原厂 NAND | ~75-85x | 高 | 波动最明显，严重依赖 AI NAND/eSSD 价格持续 |
| SanDisk | 原厂 NAND | ~50-65x | 高 | 与铠侠同方向，高弹性高风险 |
| 西部数据 WDC | 原厂 HDD | ~29-35x | 中 | 两种情景都紧缺，相对需求更稳定 |
| 希捷 Seagate | 原厂 HDD | ~70-82x | 中 | 双寡头格局清晰，现金流强，但 P/S 已很高 |
| 江波龙 | 模组中游 | ~49-53x | 高 | 最受益涨价与库存重估，但无原厂定价权 |
| Silicon Motion 慧荣 | 主控芯片（A 级） | ~55-60x | 中 | 原厂退群、企业级补位创造更好生态位 |
| Phison 群联 | 主控 + 模组（A 级） | ~20-25x | 中 | 弹性好但不算最高透支档 |

**铠侠（Kioxia）缘起流变**：源头在东芝——NAND 闪存本身就是东芝发明的（1984 年研究员舛冈富士雄发明 NAND 闪存），东芝是 NAND 的"祖师爷"。2017 年东芝因美国核电业务（西屋电气）巨亏，急需现金，把存储业务以约 2 万亿日元卖给贝恩资本牵头的财团（SK 海力士、苹果、戴尔、希捷等参与）。2018 年成立"东芝记忆公司"（TMC），2019 年 10 月正式改名 Kioxia——名字是组合词：kioku（日文"記憶"，记忆）+ axia（希腊语 αξία，价值）= "记忆的价值"，中文译名"铠侠"。现状：全球 NAND 闪存第二大/第三大供应商（与西部数据合资运营日本境内闪存工厂），份额约 13-18%，核心做 NAND 不做 HBM。在 AI 存储叙事里位置微妙——虽然是 S 级原厂，但赌的是跟住英伟达 CMX 框架，在英伟达画的格子里赌"SSD 这一层能接住多少溢出来的需求"。

**主控芯片厂商：Phison（群联）与 Silicon Motion（慧荣）**：两个都是台湾公司，在存储产业链里扮演同一角色——**主控芯片厂商（A 级，核心配套层）**。主控芯片是 NAND 颗粒的"大脑"——NAND 颗粒本身不能直接用，需要主控芯片管理数据读写位置、磨损均衡（闪存有写入寿命限制，让各区块均匀使用）、错误检测和纠正、缓存管理等。模组厂（金士顿/江波龙）从原厂买来颗粒后，必须配主控芯片才能组装成 U 盘/SSD。Phison 和 Silicon Motion 就是做这个"大脑"的。

- **Phison（群联电子）**：台湾公司，2000 年成立，创始人潘健成。业务是主控芯片设计 + 模组（两条腿走路），既卖主控给模组厂，自己也做模组。P/E ~20-25x，透支程度"中"，"弹性好但不算最高透支档"。因既做主控又做模组，业务更分散，PE 在两家里更低。

- **Silicon Motion（慧荣科技）**：台湾公司，1995 年成立。纯主控芯片设计（更专注，不做模组）。P/E ~55-60x，透支程度"中"，"原厂退群、企业级补位创造更好生态位"——原厂全做 HBM 放弃中低端时，Silicon Motion 在企业级市场补了位，反而获得更好生态位。PE 比 Phison 高一倍多。

| | Phison 群联 | Silicon Motion 慧荣 |
|--|------------|---------------------|
| 业务 | 主控 + 模组（两条腿） | 纯主控芯片（更专注） |
| P/E | ~20-25x（相对便宜） | ~55-60x（贵一倍多） |
| 生态位特点 | 弹性好但不算最高透支 | 原厂退群后补位，生态位改善 |

**王煜全判断**：
- **美光、SK 海力士是好公司**：PE 不高（利润暴涨导致 PE 降下来）、长期需求缺口在、技术水平强。美光透支程度最低；SK 海力士因韩国股市暴跌反而是上车机会。
- **三星不是好投资标的**：PE 已 50 倍，业务太分散（HBM 利润高但手机利润不高），涨起来的空间不一定大。
- **铠侠、SanDisk 透支程度高**：过去涨了几十倍，但未来透支程度高，长期不看好（没有话语权）。
- **HBM 企业已涨过**：不会再有下一个十倍增长，但未来几倍可能性大（随业绩实实在在增长）。中低端企业（如江波龙）已涨起来，反倒未来不能兑现。

### 三、长鑫存储

- **HBM**：刚进入初步量产，与龙头相差一代以上，考虑良率等因素，产能释放还有 2 年以上。
- **DRAM**：已进入规模量产阶段，预期将承载 DRAM 的需求释放。
- **机会窗口**：三星/美光/海力士切换到数据中心，放弃消费市场 → 长鑫未来两年可在中低端稳固。高端再慢慢吃。
- **长鑫与腾讯签了 200 亿服务器 DRAM 长协**，说明腾讯要搞自己的系统。海外 DRAM 现货价格比国产高 30%。
- **中美隔离下的挑战**：未来三五年中美隔离，中国能保证得好；但长期要看能否从隔离环境长出世界竞争力——需要主动出去（东南亚、欧洲、美洲）竞争。

### 四、市场充分定价阶段的波动

- **存储已被充分定价**，市场关注预期兑现。美光股价持续上行，但 10 日隐含波动率同步抬升——市场已在交易"高预期下还能否继续超预期"。
- **隐含波动率**：美光历史波动率达 123，隐含波动率接近 100，日均波动 7% 左右是正常状态。

> **什么是隐含波动率（Implied Volatility）**：先要理解期权——期权是一种股价"保险"，你付一笔钱（期权费）买一个权利，未来以约定价格买入/卖出某只股票。隐含波动率就是从"保险费"的价格反推出来的：大家都觉得未来股价会大起大落（不确定高）→ 抢着买"保险" → 期权费变贵 → 隐含波动率高；大家觉得未来平稳（不确定低）→ 没人买"保险" → 期权费便宜 → 隐含波动率低。**关键特点：不判断方向（涨还是跌），只反映市场预期未来波动的幅度**。雨伞比喻：暴风雨要来了雨伞涨价，不用看天气预报，光看雨伞价格涨多少就能反推市场觉得风暴多大——隐含波动率就是"从雨伞价格反推出的风暴预期"。课程用法：美光股价上涨但隐含波动率同步抬升，说明市场已在交易"高预期下还能不能超预期"，隐含波动率接近 100 ≈ 日均波动 7% 是正常状态。翻译成大白话：股价越涨越高，大家越紧张，预期打满后稍有利空就可能大幅跳水。对应王煜全判断——存储已充分定价，股价高位 + 隐含波动率高 = 随时可能大波动（方向不定）。
- **2029 年风险预测**（王煜全的两个小预测）：
  1. **韩国经济 2029 年受重创**，恢复时间比美国晚很多（美国可能几个月回来，韩国跌下去迟迟恢复不了）。因产业结构太单一。
  2. **SK 海力士可能被收购**：大涨大跌中，海力士因业务单一（只有内存）容易受冲击，甚至可能被美国公司（如英伟达）接收。美国公司常在低价时捡便宜。
- **周期规律**：一定会先跳水，甚至有公司破产，然后回升。破产回升过程中头部公司会实现兼并并购，再继续发展。

#### 讨论补充：2029 年大波动预测的完整推演

王煜全的 2029 年预测不是拍脑袋，而是**多个维度的时间节点在 2029 年汇聚形成共振**。四条线索：

**线索 1：存储产能周期——2027 扩产→2029 释放→过剩**
- 现在到 2027：存储严重短缺，长协锁定下厂商开始大规模扩产
- 2027 左右：新产能陆续落地
- 2029 前后：产能充分释放 → 中低端内存从短缺转为过剩 → 价格回落
- 高端 HBM 可能到 2030-2031 年才接近满足，但中低端会先过剩

**线索 2：AI 产业成熟度——从"导入期"迈入"展开期"**
- 导入期（现在）：建基础设施、烧钱试错，预期不断上调
- 展开期（2029 前后）：行业规律被找到，开始在各行业扩散
- 危险点：大家以为扩散"立刻立竿见影"，但现实兑现跟不上 → 过高预期遇上现实 → 大跳水
- 类比互联网泡沫：1999 年方向没错，但当时企业还没赚钱，预期透支 → 2000 年破裂

**线索 3：金融周期与政治周期叠加**
- 2028 美国大选：王煜全认为不会"伤筋动骨"（特朗普还在台上）
- 2029：政治清算力量可能爆发 + 产业波动 + 金融周期共振 → 风险最大
- 原话："2028 年的波动不会伤筋动骨，因为特朗普还在台上，而最狠的波动是要清算特朗普的波动。"

**线索 4：科技股的天然脆弱性**
- 存储企业已被充分定价，隐含波动率高，一旦有风吹草动（财报不及预期、政策变化、产能过剩信号）就容易引发连锁抛售

**为什么韩国受冲击最大**：

| 维度 | 美国 | 韩国 |
|------|------|------|
| 产业结构 | 多元化（科技+金融+消费+医疗） | 极度单一（存储+半导体为主） |
| 冲击传导 | 多个产业分散吸收 | 存储一跌全跟着跌 |
| 恢复能力 | 几个月回来 | 跌下去迟迟恢复不了 |
| 政策工具 | 美联储+财政部工具齐全 | 韩国工具有限 |

比喻：韩国经济像"只有一条腿的桌子"——存储景气时这条腿很强，但存储一跌整张桌子就塌了。美国是"很多条腿的桌子"，一条腿断了其他还能撑。

**海力士为什么可能被收购**：
- 业务最单一（只做内存，不像三星有手机分散），大涨时最猛、大跌时最脆弱
- 大涨时过度狂热（业务单一利润集中，容易被炒到极致）
- 大跌时最容易摧毁（没有其他业务缓冲）
- 美国公司爱捡便宜（原话："美国公司经常捡这种便宜，在你不行的时候我就把你公司就捡走了"）；英伟达如果海力士有被收购机会一定收

**三星为什么"损失惨重"但不一定被收购**：业务多元化（手机+家电+半导体），存储跌了手机还能撑一部分；体量太大、业务太多，不会被收购；但正因为分散，存储大涨时涨幅不如海力士集中，大跌时损失惨重。

**完整推演路径**：
```
2025-2027：存储短缺 → 长协锁定 → 厂商大规模扩产
           AI 产业在导入期，预期不断上调
           资本大量涌入（CapEx 7000 亿→1 万亿）

2027-2028：新产能陆续落地
           HBM 短缺开始缓解
           中低端存储价格开始松动
           2028 美国大选，政治波动叠加

2029：     产能充分释放 → 中低端过剩
           AI 产业"一只脚迈进展开期"，扩散速度不及预期
           过高预期遇上现实 → 大跳水
           科技股因充分定价 + 高隐含波动率 → 连锁抛售
           韩国因产业结构单一受重创
           海力士可能破产或被收购
           头部公司借低价并购整合

2029 之后：产业整合 → 恢复 → 继续发展
           美国几个月恢复
           韩国迟迟恢复不了
```

**与"这两年经济危机预言"的关系**：

| 维度 | 一般经济危机预言 | 王煜全的 2029 预测 |
|------|------------------|---------------------|
| 触发点 | 金融系统本身（债务、利率、流动性） | 产业周期拐点（产能过剩+预期透支） |
| 时间判断 | 模糊（"随时""近两年"） | 精准到 2029 年 |
| 逻辑 | 宏观金融周期 | 产业供需周期+技术成熟度周期+政治周期共振 |
| 对象 | 全球经济/金融系统 | 特定产业（存储/AI 硬件）+ 特定国家（韩国） |
| 方向判断 | 悲观（可能长期低迷） | 不悲观——先跌后涨，产业整合后继续发展 |

关键区别：王煜全不是预言经济要完蛋，而是预言一个**产业周期拐点**。"一定会先跳水，甚至有公司破产，然后就会回升"——跳水是过程不是终点。头部公司会借机并购整合，反而更强。与那些"经济危机随时可能来"的模糊预言不同，他给的是**产业供需的时间表**，不是金融系统的恐慌预测。

**预测的不确定性**（王煜全自己也说"越精准的预测概率越小"）：
- 产能落地时间可能不准：如果 2027 年扩产不及预期，过剩可能推迟到 2030
- AI 展开期速度可能比预期快：如果扩散很快，预期就不算"过高"，不会暴跌
- 政治预测最不确定："政治这个变化太快了，就一个禁令就没了"
- 核心逻辑（供给追上需求+预期透支=拐点）成立，但时间点可能前后挪一两年

### 五、CoWoS 封装：瓶颈之上的瓶颈

- HBM 必须通过 CoWoS（2.5D/3D 先进封装技术）才能和 GPU/ASIC 整合。
- GPU 自身封装与其他芯片都在争夺 CoWoS 产能。
- 按目前全球 CoWoS 规划，预计 **2026-2027 年 CoWoS 封装存在 15-20% 产能缺口**。
- 关注点：台积电（主要产能），以及非台积电但有话语权的台湾企业（联电、日月光）。

## 投资方法论要点

### 1. 抓大放小，建立面向未来的思维体系

- 变革时代不要占小山头，要找十年之内出现的英伟达。
- 技术对产业的影响分三类：**产业新增、产业增强、产业颠覆**。只是某一层内存的替代品（不能跨层使用），就是产业新增/增强，是锦上添花。
- 不是所有先进技术都重要。不关注细小技术不是不重要，是它不重要。

### 2. 投资要看跌，不只看涨

- 中低端公司涨幅可能更猛（如 SanDisk 涨 60 多倍），但下跌也不可预测——扛不住。
- 头部企业涨幅没那么猛但稳定；跟潮水涨的也会跟潮水落。
- **宁肯踏踏实实挣几倍，不冒风险追几十倍**。巴菲特一辈子没有几十倍回报，但成了最大投资基金。

### 3. 短线 vs 长线

- 王煜全不做短线择时分析，只讲中长期。要么不管时点拿三年，要么自己负责择时（跌的时候买）。
- 炒股的秘诀是预判别人的预判，比别人早一点。

### 4. 关于个股的态度

- **地平线**：不是头部，但中国自动驾驶爆发的受益者。特斯拉进来会加速自有电动车发展，地平线下半年可能有行情。
- **Momenta**：有问题——给传统车企服务，而传统车企不是未来。
- **Circle**：长期看好（数字货币证券化进入主流），长期持有三年一定涨回来。Circle 是美国金融科技公司（Circle Internet Financial，2013 年成立，创始人 Jeremy Allaire），核心产品是 USDC（USD Coin，美元币）——全球第二大美元稳定币（仅次于 Tether 的 USDT）。稳定币是和美元 1:1 锚定的加密货币，每枚 USDC 背后都有 1 美元储备（现金 + 短期国债）支撑，价格稳定，可当"区块链上的美元"用。Circle 做的事：发行 USDC、管理美元储备、提供基于区块链的支付和金融基础设施（跨境支付、结算等）。王煜全看好逻辑：稳定币正从加密货币圈子的"边缘实验"进入主流金融体系，被传统银行、支付网络甚至政府监管接受——Circle 作为 USDC 发行方是这个趋势的核心受益者。短期有波动（2026 是政治波动年），但持有三年一定涨回来。
- **云迹**：机器人股有两三年行情，实实在在有收入，等进沪港通。
- **寒武纪**：挺好但估值过高（9000 多亿市值），万卡集群能力是挑战，至少两年后才是相对合理预期价格。

## 互动提问精选

### 1. 云厂商收租模式与中美差距

- 亚马逊、微软等云厂商未来持续输出算力（收租模式），不是最大赢家但长期受益。
- 中美差距会越来越小，会首先在中美以外融合。AI 时代诞生的新文明很可能产生在华人里（不一定是中国，是全球化的华人——未来文明基于产缘而非地缘）。

### 2. 明略科技 vs Palantir

- 明略不是中国版 Palantir，它做的是数字化社会的营销平台（市场营销管理），用 Agent 做管理是手段。
- 用 Agent 是必要不充分条件——核心是做什么业务。看好中长期，全球化需 10-20 年（中国被世界接受是个过程，参考日本进美国的历史）。20 年尺度上能长成巨头（荷塘理论）。

#### 讨论补充：明略科技详解与两个概念

**明略科技（Mininglamp，港股 2718.HK）是什么**：企业级 AI 应用软件公司，核心是"数据 + 营销智能 + 营运智能"。创始人吴明辉（北大数学系），2006 年读研时创立秒针系统——中国第一个互联网广告效果监测平台，把电视收视率方法论引入互联网广告，至今秒针仍是中国最大互联网广告数据分析服务商。

**缘起流变**：
| 时间 | 事件 |
|------|------|
| 2006 | 吴明辉创立秒针系统，做互联网广告监测 |
| 2014 | 创立明略数据，从线上广告延伸到政府、公安、金融 |
| 2019 | 成立明略科技集团；入选科技部"营销智能国家新一代人工智能开放创新平台" |
| 2020 | 组建千人团队押注 Agent，收购微伴（企微最大社交 CRM）做企业级 AI 助理，后因技术超前于市场关闭产品线 |
| 2025 | 发布 DeepMiner、GUI 自动化模型 Mano（CUA/BUA 榜单全球前列）；11 月 3 日港股上市，"全球 Agentic AI 第一股" |

**未来预期与变量**（王煜全判断）：
- 明略不是中国版 Palantir（Palantir 做政府情报/数据平台，明略本质是营销管理平台）。
- 用 Agent 是"必要不充分"——光有 Agent 做不成大公司（类比"用 Web3 做 Facebook 会很好，但只有 Web3 做不成 Facebook"）。明略能做多大，取决于它做的数字化营销平台业务本身能做多大，而非 Agent 技术多先进。
- 关键变量：① 业务本质 vs 概念标签（别被"Agentic AI 第一股"口号唬住）；② 中国营销能力全球化进程（10-20 年，最大时间变量）；③ GUI 自动化路线的数据壁垒投入；④ 长期看好（20 年尺度成巨头），但短期慢。

**什么是营销管理平台**：帮企业管"怎么把产品卖出去、广告打给谁、投放效果怎么样"的一整套数字化系统，相当于企业的"广告大脑"指挥中心。以前投广告靠人手工找渠道、盯数据、算投入产出；营销管理平台把这些数字化自动化——采集各平台（抖音/小红书/淘宝）投放实时数据，自动分析哪波人群转化高、哪个素材效果好，指导下一步钱往哪投。明略的起点秒针系统就是这个逻辑的鼻祖（帮广告监测哪 1000 万广告费有没有水分），后扩展到营销全链路：监测 → 分析 → 投放 → 优化管理。明略做两条线：营销智能（回答"广告投得准不准值不值"）+ 营运智能（用 Agent 自动化执行营销日常操作）。

**什么是荷塘理论**：关于"指数增长 + 临界点"的形象比喻。荷花每天数量翻一倍，若第 30 天铺满整个池塘，问铺满一半是第几天？多数人直觉答第 15 天，正确答案是第 29 天——因为每天翻倍，铺满前一天正好是铺满一半。寓意：一件事突破"过半"临界点之前增长看起来慢吞吞，过了临界点就突然爆发势不可挡。王煜全用它说明明略（及中国营销能力全球化）：现在像"一两片荷叶"阶段，被世界接受得很慢；哪天"过半"了就会像荷塘后几天那样疯狂增长，一二十年长成跨国巨头。

### 3. LLM 能否理解物理世界

- 施展认为人类靠语法和单词二维结构构造观念世界——王煜全认为搞反了：**人类先构造出观念世界，再用语法和单词给它命名**。
- LLM 是真实世界的表象（命名），得不到真实世界。物理 AI（Physical AI）是理解系统，大语言模型是命名。人类有先验的、完整的理解世界的系统。

### 4. FDE（Forward Deployed Engineer）

- 中美 AI 落地根本不同：美国是数字化→网络化→云化→智能化，一步步来；中国是一步智能化。不能照搬美国 FDE 模式，但会有中国版。

### 5. 埃森哲反共识

- 挑战很大。AI 替代中小企业咨询需求是事实，但埃森哲其他部分会萎缩厉害。历史案例库如果对未来没有指导就不值钱。股息未来可能付不起。不是好的反共识标的。

### 6. 端云摆动

- 云端强了过一段时间端侧爆炸增长，端侧强了云端爆炸增长，形成回摆周期。周期在加快，端侧 AI 处理潮流预计未来三年内启动，五年十年形成。
