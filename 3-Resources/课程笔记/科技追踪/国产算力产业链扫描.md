# 课程内容

## 第7季·第9期 国产算力产业链扫描（2026-07-16）

> **主线**：AI 算力需求是**真实爆发**（来自真实使用，不是智算中心建出来的），但国产算力的机会会**高度集中**——训练看华为，推理是红海，第三梯队独立芯片公司进入淘汰赛。真正的长期机会会逐步从基础设施转向**多模态、Agent、AIGS（生成服务）和全球化应用**。这节课的核心不是找"哪只芯片股能涨十倍"，而是判断国产算力产业链的**真实机会与风险**——问题不是"谁会十倍增长"，而是"谁能活下来"。

### 核心结论（直播六要点）

1. **需求层**：平台广告推荐、多模态、编程等算力需求增长迅猛，AI 算力已成为需求拉动、健康发展的真实市场，未来还会进一步高速增长
2. **模型层**：Scaling Law 没有失效，大模型仍需持续、巨额投资来支撑需求，独立上市的国产大模型公司处于劣势，互联网大公司更容易砸钱维持领先
3. **模型层**：编程是全球统一需求，中国长期与国外有差距；多模态等细分领域中国有数据优势，有望在全球拿下份额；头部大模型公司能否做出细分定位、放弃 AGI 故事，是重要的未来信号
4. **芯片层**：训练与推理正分裂成两个市场——训练本质是通讯/工程问题，依赖芯片和芯片集群；推理更多是性能调优与资源调度
5. **芯片层**：训练看华为，推理市场红海化。制造与平台都将走向集中，华为依靠训练/推理保持一梯队领先，大 IT 公司有望在推理市场进入二梯队，独立芯片公司将决战三梯队站位，同时面临国外厂商挑战
6. **芯片层**：第三梯队企业当下面对的不是增长问题，2029 年的淘汰赛已经启动，谁能存活才是关键

| AIGC / AIGS | AI Generated Content / Service | 生成内容 / 生成服务。从"生成内容"转向"基于行为理解提供服务的"代际切换 |
| Agent | — | 智能体。能自主执行多步任务、调用工具的 AI 系统 |
| PE | Price-to-Earnings | 市盈率，市值÷净利润 |
| OpenRouter | — | 海外开源模型路由平台，可按需切换/部署各模型，收中介费 |
| Situated Knowledge | — | 立场化/场景化知识。强调知识离不开说话者的立场与所处场景 |

## 第一部分：需求层——AI 不是泡沫，需求是真实市场拉动

### 一、三类真实需求

王煜全开门见山纠正一个普遍担忧：**人工智能不是泡沫，需求是用户和市场用出来的，不是政策口号喊出来的，更不是智算中心建出来的。** 需求主要来自三类：

1. **大厂内部提效（自带流量的平台）**：Meta（脸书母公司）、谷歌、字节、腾讯等自带流量的平台，用 AI 优化广告、搜索、推荐，能直接变现。阿里的弹性相对弱一些——因为淘宝流量更多依赖外部导入（买流量），不是内生流量，用算法优化的空间就小。
2. **多模态增长**：图片、音频、视频、短剧等需求继续上升，中国在视频数据和应用场景上有优势。
3. **AI 编程和 Agent 爆发**：程序员、业务人员、普通用户大量使用，Token 消耗增长很快。这是"草根需求"，不是某个大企业拉动的。

**关键判断**：需求来自真实使用，不是智算中心建出来的。

### 二、海内外 Token 大爆发

- **国家统计局**：3 月国内日均 Token 消耗量达 **140 万亿**，较 2025 年底增长 40%。
- **字节**：2026 年 3 月豆包日均 Token 消耗量突破 **120 万亿**，较 2024 年增长 100 倍，较 2025 年底翻倍，官方预期年底突破 **500 万亿**。
- **OpenRouter 统计**：2026 年上半年 DeepSeek 份额从约 9% 升至 18%，6 月初一度接近 20%，中国模型长期在第三方排行榜霸榜。
- **价格优势**：DeepSeek V4 Flash 低端价约 0.09/0.18 美元（百万输入/输出 Token）；OpenAI GPT-5.4 Nano 约 0.2/1.5 美元；最新的 GPT-5.6 Luna 为 1/6 美元。当需求量巨大时，省钱就很重要，中国凭性价比切入海外。

### 三、国内 Token 需求结构：推理爆发中的算力分层

> 训练与推理算力占比约 1:4。关键看"算力占比"与"收益占比"的错配——有些领域吃算力但不赚钱，有些既吃算力又赚钱。

| 场景 | 算力占比 | 收益占比 | 判断 |
|------|---------|---------|------|
| 训练 | 24% | — | 基础投入，占比将随推理爆发而下降 |
| 广告/搜索/推荐 | 20% | 收益占比很高 | 大厂自己的钱，立刻见效，是大厂自建大模型的动力 |
| 大众助手（豆包等 Chatbot） | 14% | 约 8% | **不赚钱**（靠月费，国人不习惯交月费） |
| Coding/Agent | 22% | 23% | **赚钱**，增长好，值得关注 |
| 多模态 | 13% | 13% | **赚钱**，国内占比小但潜在增长大 |
| 政企 / AI for Science | 7% | 9% | 收入偶发、不连贯（卖一体机是一次性的），需观察持续性 |

**真正值得关注的三个需求**：
1. 大公司内部普遍有自己的需求（这就是它们砸钱做大模型的动力）；
2. **Coding/Agent**——爆发但规模尚小；
3. **多模态**——中国有数据优势，且能赚到钱。

### 四、Coding/Agent：引领需求爆发，但还不是大头

- **三种估算方法**测算中国 Coding/Agent 市场规模（约在 2–25 亿，落点约 8 亿）：
  1. **用户法**：中国 GitHub 用户规模 1070 万（近似程序员规模），按 60–160 元月费、不同转化率，市场 1.16–24.65 亿元；
  2. **Token 等价法**：基于日均 140 万亿 Token，按 Coding 占比 1%–8%、Token 单价 0.2–1 元/百万，市场 1.02–40.88 亿元；
  3. **厂商收入反推**：智谱 2025 年 API 收入 1.904 亿元，按其 Coding 占中国市场的 5%–30%，市场 0.79–25.7 亿元。
- **结论**：市场还不大（几个亿），但快速长大；国内大厂已全部进场（阿里、字节、腾讯、百度、华为、小红书、京东）。
- **一个警示**：编程是全球统一需求——编程语言本质是全球共用的，不像芯片那样"别人不卖你就有替代进口的机会"，"谁家好用用谁"。所以国内人人做编程工具这件事"应该不靠谱"，未来有很多不需要做、也做不了。

### 五、多模态与出海：收入增长快，但只有部分回流

- 综合可灵、MiniMax 等已上市企业的数据，预计 **2026 年中国 AI 企业出海收入在 8–15 亿美元规模；2029 年预计增长到 120–240 亿美元**——倍数级增长。
- **但有个关键问题**：中国模型打入国际市场，收入并不全部回流——海外客户可通过 AWS/海外 GPU 云调用中国模型。典型是 **OpenRouter** 这类流量中介：它把中国的开源模型部署到自己机房，向第三方收 Token 费，收 5% 中介费以外的利润就归自己，不给模型方分成。

## 第二部分：模型层——Scaling Law 没失效，中国阶段性追赶

### 一、Scaling Law 没有失效，模型能力继续提升

- 模型能力仍在持续提升，基础模型竞争没有结束。Mythos 起来后 OpenAI 迅速应战；中国也可能半年达到 Mythos 水平（不确定但可能性大）。最热的编程/Agent 领域里，Claude Code 之后立刻有 Codex 跟上，说明**基础层、能力层的竞争还没停止**。
- 对中国不是特别好的消息：**中国擅长工程化、性能调优和规模化落地，但这些优势最适合在技术革命放缓后发挥。** 只要 Scaling Law 存在，能力提升（可能翻倍）就比节能增效（只能提升几个百分点）重要得多。

### 二、中国长期"差半年到一年"，切入时机很重要

- 国外一个突破（如 Mythos），中国和它的差距拉远一点；半年到一年后慢慢拉近；一年后又有新突破，又拉远。**中国可能长期处于"差半年到一年"的追赶状态。**
- 现实打法不是全面冲 AGI，而是**在细分领域集中资源，依靠数据优势、应用场景和工程化做 me-better**——尤其在视频、多模态、应用出海上形成领先。这是"技术革命趋缓后工程厉害才有用"的逻辑（类比生物医药的 first-in-class → me-better）。
- 技术还在迭代 → 必须持续高额研发投入 → 能跟得上这么大研发的中国公司屈指可数。

### 三、大模型公司分化：大厂模型更有优势

- **独立大模型公司**（智谱、MiniMax、Kimi 等）：难点在于持续研发要烧钱，但"模型好 ≠ 能赚钱"；上市后市场不再只听 AGI 故事，会直接问收入、现金流和增长预期。
  - **上市融资的两面性**：上市前估值高、能融巨资（投资人赚的是"上市估值暴涨"的钱，如李嘉诚 2008 年投 Facebook 百亿美金估值、2012 年上市 2000 亿美金翻了 20 倍）；但上市后融资反而严苛——已经有了千亿市值再融百亿，会被要求明确增长预期，"讲不出去故事"。
- **大 IT 公司自有模型**更有优势（字节的豆包、腾讯的混元、阿里的通义千问）：有流量、业务和应用场景，模型投入能反哺广告、推荐、搜索、办公、编程等业务。
- **DeepSeek 是另一种逻辑**：低价和开源能打开海外使用量，但使用量不等于收入回流，商业闭环仍需观察。
- **造芯传闻是"两年以上的假故事"**：声称要造芯片的大模型公司（DeepSeek/智谱）理论上作为应用方懂算法，但芯片制造（流片、封装）是另一套 know-how。中国的"博通"（Broadcom，帮谷歌做 TPU 的角色）还没出现。

### 四、AGI 不会很快到来，关键是场景化数据

- 现有互联网语料缺少**场景、立场、过程**，只剩"干巴巴的知识"，很难直接通向 AGI。
- 王煜全重点提出三个概念：
  - **Situated Knowledge（立场化/场景化知识）**：每句话背后都有说话者的立场和潜台词，互联网数据把这些抹掉了，只剩脱离现实的内容；
  - **Cultural AI（文化人工智能）**：机器人理解场景的核心不是物理世界本身，而是背后的文化含义（看显示器不是看显示器，是看它显示什么、人在干什么）；
  - **Distributed Cognition（分布式认知）**：认知分布在人与多个智能体、环境构成的系统里，而不是集中在一个载体。
- **未来真正重要的不是结果数据，而是过程数据、场景数据、行为数据**。机器人、智能制造、健康数据、手机端行为智能都需要**重新采集过程与场景**（无锡考察案例：为汽车做测试仪器的企业原本只采结果数据，做智能化时才发现必须采运行轨迹、场景等过程数据）。
- **推理**：训练小朋友能做到、训练 AI 却做不到的事，恰恰说明人的智慧没那么简单；三五年内大家会重新对人的智慧肃然起敬。
- **延伸（人机融合）**：王煜全自述最近在研究 cyborg intelligence（人机融合智能）。他纠正 Jeff Hawkins（杰夫·霍金斯，美国神经科学家）的"记忆预测结构"——记忆应是"认知预测结构"：人先天先形成认知、再行动（谋定后动），行动结果再回馈到认知。未来人机协同是"N 个人 + N 个机器的系统融合"，在认知流程里混合完成，形成分布式认知。

## 第三部分：芯片层——训练与推理分离，国产机会在推理

### 一、训练与推理是两个市场

- **训练**：需要万卡集群、强芯片、强通信和系统协同能力，本质是**大规模工程问题**。一个模型的万亿参数要同步调整，任务不能分割。
- **推理**：单个任务不一定需要万卡，百卡、小集群就能支撑，核心是**高并发、低延迟和资源调度**（100 个百卡根本不是"一万卡协同"）。
- **训练芯片能用于推理，推理芯片未必能用于训练**（理论上最优的计算中心是既能训练又能推理、算力足够高；中国没有，所以"高算力放训练、算力不够的放推理"）。

### 二、训练看华为，英伟达仍是未来两三年刚需

- 国产训练芯片真正能打的主要是**华为**，其他都不行；未来两三年训练侧仍需英伟达支撑（H2 传闻正在谈判进中国，今年很可能达成）。
- **华为的核心优势是通信**：华为是通信公司，对通信的理解比英伟达还强；万卡集群的通信调度能力甚至比单芯片算力还重要。这不是技术问题，而是大规模工程协同问题。
- 训练侧并非稳健替代窗口，但**推理侧打开了国产替代窗口**——难点在商业上：大客户不会轻易接受"七国八制"（多家芯片混用），会优先选稳定、成熟、可规模交付的头部供应商。

### 三、推理的工程优化：PD 分离 + KV Cache + FP8

- **PD 分离（Prefill/Decode 分离）**：把"处理输入上下文"（密集矩阵计算）与"逐字生成"（依赖显存带宽）两阶段交给不同芯片池，通过传输 KV Cache 实现异构协作。Kimi 与清华研究：32 张 H200 做 Prefill + 64 张 H20 做 P/D 池，相对 96 张 H20 同构基线，吞吐 +54%、首 Token 延迟 -64%。
- **KV Cache**：把反复调用的数据缓存起来，省 Token、省钱，已成业内共识。
- **FP8 低精度**：人工智能是推理不是精确数学计算，FP8 的推理结果反而更好，还能提升训练效率、降低模型成本。华为 950 系列（950PR 面向 Prefill/推荐、950DT 面向 Decode/训练）已做 FP8 适配。
- **警示**：这些优化说明中国推理成本低是**工程优化省出来的，不是成本本身比国外便宜**。中国低价策略长期看有风险——"某一天会不会有人站出来说，你背后也用的英伟达，成本没那么低却卖那么低"。

### 四、"万卡集群"的三层含义（防炒作）

| 维度 | 含义 |
|------|------|
| **训练** | 万卡集群**真正的价值所在**——模型参数提升需要超大规模协同计算 |
| **推理** | 万卡只**决定上限**——单一推理任务 10–100 块小集群就够 |
| **供货** | **大多数"万卡概念"的本质**——只是说明拥有提供万卡的能力，与能否完成规模训练/推理无直接关系 |

### 五、近一年国产算力关键进展

> 核心观察：**训练类进展少，且基本都指向华为；推理类进展多，且都在大厂。**

| 时间 | 企业/案例 | 训练/推理 | 突破点 |
|------|----------|----------|--------|
| 2025/4 | 华为 Pangu Ultra | 大规模预训练 | 8192 张昇腾 NPU 完成 1350 亿参数 Dense 模型、13.2 万亿 Token 训练 |
| 2025/6 | 华为 CloudMatrix384 | 超节点推理 | 384 颗昇腾组成统一系统，支持 PD 分离、专家并行、分布式 KV Cache |
| 2025/7 | 智谱 GLM-Image | 国产全流程训练 | 昇腾 Atlas 800T A2 + MindSpore 完成从数据到训练全流程 |
| 2026/2 | 智谱 GLM-5 | Agent 工程+国产适配 | 异步强化学习训练长程 Agent，训练初期即考虑国产适配 |
| 2026/5 | 智谱 ZCube | 千卡级推理网络 | 只改网络拓扑，交换机/光模块支出降 33%、推理吞吐提升 15% |
| 2026/5 | 阿里 RTP-LLM | 工业级推理引擎 | 服务超 1 亿用户，缓存复用率提升 215% |
| 2026/6 | 美团 LongCat-2.0 | 5 万卡国产训练 | 公开最大规模国产芯片训练案例，1.6T 参数，推测为华为 910C |
| 2026/6 | 智谱 GLM-5.2 | 百万上下文+长程 Agent | 首日完成九类国产算力平台适配 |

- **异构集群成熟度**（多芯片混算的难度）：L1 多个独立同构池（已用）→ L2 同一模型适配不同芯片（厂商自适配）→ L3 不同厂商共同运行（研究阶段，最高千卡级）。**任意混算难长期维系**——即使同是英伟达，H200→A100→B200 也有代差，计算中心最好"不混"。

## 第四部分：产业评估——格局高度集中，第三梯队淘汰赛

### 一、国家级算力过剩 vs 大厂主导算力是真实主线

- **国家级算力名义规模巨大但过剩**：约 1085 万架标准机架、平均上架率约 60%、名义总算力约 962 EFLOPS。发改委专家文章提到部分西部中心**空置率超 50%、个别机架上架率不足 10%**；路透调查显示受访政府支持中心负载约 20%–30%，18 个月内取消项目超 100 个。
- **需求从大模型来，不从建中心来**：你手里没有大模型，谁会找你？因此"帮国家建算力中心"这事别干了——会算力过剩；"帮字节建算力中心"这事可以干——但字节干吗不自己干？
- **真实算力紧张的是**：字节、腾讯、阿里、美团等头部互联网公司（有流量、有模型、有应用、有真实 Token 消耗。字节对算力短缺的理解比国企深入得多）。

### 二、三层梯队与市场格局预估

| 梯队 | 成员 | 特点 |
|------|------|------|
| **第一梯队** | 华为 | 训练+推理都具备最强替代能力，唯一能对英伟达形成替代的 |
| **第二梯队** | 阿里平头哥、百度昆仑芯、（潜在）字节/高通合作 | 有云、有模型、有内部需求 |
| **第三梯队** | 寒武纪、海光、摩尔线程、沐曦等独立芯片公司 | **没有足够内部需求，只能依赖外部采购**，而大客户更倾向头部方案 |

- **雪上加霜**：高通与字节正谈数据中心 AI ASIC 合作（字节计划采购数百万颗/数百 MW 高通 AI ASIC，路透更披露商谈定制芯片设计服务）。高通是"开拓新生意"所以更积极，字节是"另一种模式实现有芯片"。一旦成功，二梯队再添强手。
- **市场格局预估（2029，保守口径）**：华为约 50%、阿里/百度等大 IT 公司约 30%、独立第三方约 20%。**王煜全客观修正**：实际可能是华为 60–80、二梯队 20–30、三梯队不到 10%。
- **为什么一个上下游锁定消息都没有**：头部（华为）供不应求、不需要锁；尾部（小公司）不值得锁（锁定得有交付能力，没有英伟达那种能力锁了也没用）。锁定是重大利好，谁不想要？没有公开，就是没有。

### 三、第三梯队生存测算（2029 年 50 倍 PE、30% 净利率反推营收）

> 用"今天的市值"反推"2029 年要支撑这个市值需要多少收入"，看差距。

| 公司 | 市值快照（7/15） | 2029 年需达到的营收 | 当前营收 | 差距 |
|------|-----------------|-------------------|---------|------|
| 寒武纪 | 8400.28 亿元 | 约 560 亿元 | 65 亿元 | 约 8 倍（6/7/8/9 四年翻 8 倍） |
| 海光信息 | 7479.02 亿元 | 约 499 亿元 | 100 亿出头 | 约 3–5 倍 |
| 摩尔线程 | 3003.43 亿元 | 约 200 亿元 | 15.1 亿元 | 10 倍以上 |
| 沐曦 | 3364.84 亿元 | 约 224 亿元 | 16.4 亿元 | 10 倍以上 |

- **数量级问题**：眼前估值和四年后目标差着一个"十倍数量级"，四年能不能翻十倍是核心问题。极少数能达到，但一定不会是普遍的（大 IT 公司主导时是"批量采购"头部）。
- **寒武纪的具体处境**：65 亿收入 ÷ 5 万元/片 ≈ 10 万颗芯片，意味着它正在跨过"万卡供货能力"（好消息）；但坏消息是——平头哥、昆仑芯自己有云计算要支持，自己的云就消耗 10 万卡。寒武纪的**第一大客户是字节，但字节的第一大供应商是华为**。
- **国家队订单逻辑减弱**：过去两年寒武纪订单来自电信、联通、移动主导的建设周期；未来国家队饱和，这块订单会萎缩。

### 四、2026–2029 国产 AI 芯片市场空间估算

| 年份 | 下行（亿元） | 基准（亿元） | 上行（亿元） |
|------|------------|-------------|-------------|
| 2026 | 700–950 | 800–1100 | 1000–1300 |
| 2027 | 600–850 | 900–1300 | 1350–1900 |
| 2028 | 700–1050 | 1150–1650 | 1850–2600 |
| 2029 | 850–1300 | 1450–2100 | 2400–3300 |

- 供给端（产能规模）641.9–1190 亿、资产端（预算规模）128–1207 亿，基准规模带 800–1100 亿。
- **格局演化**：2026 供给决定份额 → 2027 商业客户锁定 → 2028 软件与新代产品筛选 → 2029 平台化与专用 ASIC 并存。
- **中芯国际先进产能归属头部**：第一大客户收入占比 8.0%、前五大合计 35.8%（对照：台积电 50% 产能给了英伟达）。中国还没形成芯片头部集中——谁能形成，谁才有生存空间。
- **产业上下游观点**（PPT 引用）：腾讯 CFO 罗硕瀚——中国设计的 ASIC 正从国内外晶圆厂获得更多供应，供应商通过长协定锁定未来 3–5 年收入；百度昆仑芯 CEO 欧阳剑——最终会出现一批头部芯片公司，不是每家都养芯片团队。

### 五、核心结论：投资安全性 > 增长性

- **不能从"AI 算力需求增长"直接推导出"所有国产芯片公司都有长期价值"**。产业增长集中到头部，尾部被淘汰。
- **判断公司要看**：真实需求、大客户绑定、规模交付能力、产业话语权、估值能否被未来收入支撑。
- **风险提示**：不要把小概率的高倍回报当成产业规律；国产算力不是没机会，而是机会越来越集中。**这板块不要轻易炒芯片公司——它更多的问题是"未来谁会死"，而不是"谁会十倍增长"。**

## 第五部分：更长期的机会——应用侧

### 一、开源模型使用量 ≠ 收入回流

- 中国开源模型在海外使用量增长很快，但如果被 OpenRouter 这类平台部署，收入被第三方拿走。用户消耗的是中国模型能力，钱却没回到中国公司。
- **必须建立官方 API、海外品牌和用户直连关系**，把钱赚到自己手里。这是大模型公司的"生死抉择"——聪明地建品牌能大胜，不建海外品牌可能死掉。

### 二、AIGC → AIGS：从生成内容到生成服务

- 产业机会会从基础设施逐步向应用侧迁移（"前移"往下走 + "扩散"向周边）。
- **代际切换**：之前三年是 AIGC（生成内容）的逻辑，之后三年是 AIGS（生成服务）的逻辑——核心是对你行为的理解（行为智能），基于手机给你提供服务。今年开始，明后年渐入佳境，三年后回头看是拐点。
- **具体方向**：多模态、视频生成、AI 短剧（如红果短剧、海外 ReelShort、传音为非洲做 AI 短剧）、Agent、手机端 AIGS、全球化应用。
- **"下一个腾讯"**：一定会出巨头，但还在"小松未出蓬蒿"的阶段。现在要做的是把规律搞透，等它冒头时能第一时间识别——这是特训营的目的，不是告诉你是谁，而是让你能识别出下一个巨头。

### 三、对基础设施小票的态度

- 英伟达百倍暴涨后是高带宽缓存，下一个或许轮到某个周边配件（如机柜铰链）——但那是"被带涨的运气"，命运不攥在自己手里，比买彩票还难。**宁肯放弃这类机会，不去探索。**

## 投资方法论要点

1. **确定性 > 回报**：没有确定性的高回报早晚输回去；复利效应的核心是求稳不求高回报。不问"谁是百倍股"，问"谁是确定能赢的"。
2. **挣自己能确认的钱**：投中百倍股基本是短剧里的故事，现实是"综合回报"——深耕一个行业已久的人才有优势。
3. **技术判断 vs 产业判断**：站在"较超然"的四个角度看——技术站工程师角度、产业站生态（国家）角度、应用站用户角度、企业站老板角度（此框架来自悦行远方的提问，王煜全高度认可并申请引用）。

## 互动提问精选

### 1. 商业航天（郑新芬）

- 长期看好中国航天（中美以国家对抗为主），但**长期不看好商业航天**：美国商业航天有需求（政府给海量项目 + 太空互联网市场），中国长征是国家队，政府给的是长征项目；太空互联网市场中国 20 多年前就"村村通"了，远小于美国。

### 2. 台积电（William）

- 不看股价看市盈率、市销率（市盈率可被"藏"——投到基建研发里；市销率藏不掉）。台积电市盈率约 35，对高增长公司是合理区间，**可长期持有**，因为长期稀缺、需求扩大。扩展是阶梯式的（建厂咣当扩一块），亚利桑那厂建成会跳一块。

### 3. 算力环节排序（涂眠眠）

- 芯片设计、封装、散热、服务器集成、算力调度五环节里，**最值得看的是服务器集成和算力调度平台**；后面的都差不多、不值当看。算力调度平台未来若以大集群为主，作用会越来越小。

### 4. 生产级可靠算力（车纲）

- 判断"靠谱算力"的核心其实是**看模型行不行，不是挑算力**——模型好，背后支撑它的算力绝不会差，所以挑模型就好。

### 5. MiniMax vs 智谱（凯凯苏）

- 两家逻辑其实一样（独立大模型公司在中国难生存、要全球化），不应该有那么大分化，"一个涨一个跌说明存在市场愚蠢"。智谱：GLM-5.2 很好但风险大（编程全球统一、且清华背景有政府关联、政企收入难持续），未来两年有政府挺；MiniMax：全球化本身可能赢，但 CEO"AGI 前不领工资"说明全球化不坚决。

### 6. 端侧 AI 手机（图南）

- 换机动力的来源是"懒惰需求被击穿"（不用掏手机、说话就能做事）也是够的换机理由；千元机"补充苹果"是现实打法。判断展开期看"过去做不到的能力"是否真正出现。
