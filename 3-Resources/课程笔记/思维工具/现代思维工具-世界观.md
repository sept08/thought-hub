## 一、基本世界观（六条）

世界观是回答"世界如何运转"的底层假设和认知框架。你可以在很大程度上自主选择价值观和人生观，而对于世界观，却是你认识到什么程度，就得接受到什么程度——因为这个世界不是按照你的意志创造的。

### 第一条：叙事——宇宙的第一性原理

#### 1.1 第一性原理的追问

**定义**：探讨"这个宇宙或世界"的第一性原理是什么？

**思考与演变**：
- 早期认知：世界的第一性原理是物理定律，其他学科皆由其派生
- 后来的疑问：物理定律背后是否还有更深层的存在？
- 疑问来源：物理学界意识到，我们所处的宇宙可能并非唯一，可能存在无穷多各式各样的其他宇宙，那些宇宙未必遵循我们这个宇宙的物理定律

#### 1.2 沃尔夫勒姆的探索：计算比物理更基础

[[斯蒂芬·沃尔夫勒姆]]发起 Wolfram Physics Project (WPP)，目的是从更基本的原理出发推导出整个物理学。

沃尔夫勒姆认为：物理定律不是最底层的"第一性原理"，真正的第一性原理是**计算规则**。

##### 计算 ≠ 数学

这是沃尔夫勒姆思想体系的基石：

| | 数学 | 计算 |
|--|------|------|
| **研究对象** | 结构、数量、关系 | 过程、变换、演化 |
| **核心操作** | 证明、推导 | 执行、运行 |
| **典型工具** | 方程、定理、证明 | 规则、程序、模拟 |
| **思维方式** | "这个方程的解是什么？" | "按照这条规则运行下去会发生什么？" |
| **确定性来源** | 逻辑推导 | 规则执行 |

**例子**：
- 数学问题：给定方程 x² + y² = 1，求满足条件的点
- 计算问题：给定一条规则，从初始状态开始执行 1000 步，系统会变成什么样？

##### 什么是"计算规则"？

最简单的例子——**元胞自动机规则 110**：
```
规则：一行格子，每个格子是黑或白
      下一行的状态由上一行的3个格子决定
      
      比如：
      黑黑黑 → 白
      黑黑白 → 黑
      黑白黑 → 黑
      ...（共8种情况）
```

这**不是方程**，**不是公式**，就是一条**操作指令**："如果你看到这个图案，就把它变成那个"

Wolfram Physics Project 的核心是**图重写规则**：
```
初始状态：一个简单的图（点和边）
规则：找到匹配的子图 → 替换成另一个子图
不断执行 → 图变得越来越复杂 → 涌现出空间、时间、物质
```

##### 为什么计算比数学更基础？

- 数学擅长描述"状态"，不擅长描述"过程"
- 计算不需要方程，只需要规则
- 从简单规则可以涌现出无限复杂的行为
- **宇宙本身可能就是一个计算过程**——不断执行规则，从未停止

> 数学是人类发明来描述静态结构的工具。计算是自然界本身的运作方式。物理定律不是方程，而是计算规则执行后涌现出来的规律。

##### 为什么必须假设时空是离散的？

**核心问题：连续的东西"不可计算"**

| 连续 | 离散 |
|------|------|
| 一段线段包含**无穷多个点** | 一段线段包含**有限个格子** |
| 信息量**无穷大** | 信息量**有限** |
| 无法用有限存储表示 | 可以用有限存储表示 |
| 无法用有限步骤处理 | 可以用有限步骤处理 |

**计算的本质要求**：
- 计算需要存储状态 → 有限存储才能存储
- 计算需要执行步骤 → 有限步骤才能执行
- 计算需要输出结果 → 有限结果才能输出

**连续时空的困境**：如果空间连续，一个立方厘米的空间包含无穷多个点 → 要描述它的完整状态，需要无穷大的存储 → 这就**根本无法计算**

**沃尔夫勒姆的逻辑链条**：
```
前提：宇宙的第一性原理是计算规则
推论：宇宙必须是可计算的
再推论：宇宙必须是离散的（否则不可计算）
```

所以沃尔夫勒姆假设：
- **空间** = 一堆离散的点（他称为"atoms of space"，空间的原子）
- **时间** = 一拍拍的离散步骤

**目的**：把宇宙还原到最底层的可计算单元，从而探求是什么样的规则，通过不断计算，最终得到了我们这套物理定律的宇宙。

> 传统物理学用连续方程描述宇宙，是人类的**数学工具**，不是宇宙的**真实结构**。
> 
> 宇宙本身可能是离散的——因为它必须能被"运行"（计算）。

##### Ruliad：一切可能计算的纠缠极限

**Ruliad** = Rule（规则）+ Ruliad（纠缠的谐音造词）

沃尔夫勒姆的定义：**一切可能规则的纠缠极限**

**理解框架**：
```
传统物理学：物理定律 → 宇宙
沃尔夫勒姆：简单计算规则 → 图重写 → 涌现出空间、时间、物质
Ruliad：所有可能的计算规则 → 纠缠在一起的总集合
```

**关键洞见**：不是"切片"，是"视角"
- 不同观察者在 ruliad 中处于不同位置
- 从不同位置"看出去"，看到的规律（物理定律）不同
- 我们这个宇宙的物理定律，只是我们这个观察者位置看到的"局部视图"
- 其他"宇宙"不是平行的独立存在，而是 ruliad 的其他部分

**这回答了什么问题？**：
1. 为什么物理定律是这个样子？——不是"被设计成这样"，而是"我们恰好站在这个位置，看到的就是这样"
2. 物理学的基础是什么？——不是更底层的物理定律，而是**计算本身**
3. 其他可能的宇宙存在吗？——它们"存在"于 ruliad 中，但不是独立的，而是纠缠在一起的

#### 1.3 叙事比计算更基础

**核心洞见**：要让宇宙产生我们这样的物理定律，需要注入的要求是**叙事**。

##### 什么是叙事？

- 对互相关联的一系列事实的连贯描述
- 一段小故事

**叙事的基本要求**：

| 要求 | 意味着 | 需要的物理定律 |
|------|--------|----------------|
| 连贯的顺序（先走进房间，再拿馒头） | 必须有「时间」 | **狭义相对论**（确保因果关系对所有观察者一致） |
| 明确的因果关系 | 事情先后顺序对所有观察者一致 | 狭义相对论 |
| 过去确定、未来不确定 | 不确定性机制 | **量子力学**（微观粒子的内在不确定性） |
| 引力聚合物质形成稳定结构 | 有秩序、值得叙事 | **广义相对论**（提供舞台） |

> 简单说：狭义相对论提供了因果，量子力学提供了想象力，广义相对论提供了舞台。

##### 为什么叙事是第一性原理？

- 不是"上帝为了让我们有叙事才设定物理定律"
- 更科学的理解：存在无数宇宙，很多没有因果关系、过去不确定未来是死局，那些宇宙不会有智慧生物
- 我们幸运地生在一个**允许叙事的宇宙**

#### 1.4 叙事与自我

**核心洞见**：
> 叙事不是因为「我」而存在，「我」是因为叙事而存在。

**自我的本质**：
- 自我不是一个实体
- 自我只是「叙事重心」（center of narrative gravity）——哲学家丹尼尔·丹尼特
- 因为要叙事，需要一个讲述者和主人公，这就是「自我」

**意识的本质**：
> 你一直都在给自己讲故事，你才有了意识。

- AI 没有意识，因为训练好就直接上线，没有自己的经历，没有历史叙事

#### 1.5 叙事的三个作用

##### 作用一：触发行动

**机制**：把事实连贯陈述 → 建立因果关系 → 形成世界模型 → 做出预测 → 触发行动

**日常例子**：
- 伸手拿杯子喝水 → 预测这个动作能让我喝到水
- 继续工作 → 相信工作能带来回报这个叙事

**自由能原理（卡尔·弗里斯顿）**：

自由能原理是神经科学家卡尔·弗里斯顿提出的统一大脑理论。核心思想是：**大脑本质上是一台预测机器，它的核心任务是不断预测感官输入，并最小化预测误差（即"自由能"）**。

**自由能 ≈ 预测误差 ≈ 惊讶**

| 术语 | 通俗理解 |
|------|----------|
| 自由能（Free Energy） | 预测与现实之间的差距 |
| 惊讶（Surprise） | 当现实与预期不符时的心理冲击 |
| 预测误差 | 你预测会发生A，实际发生了B，误差=B-A |

**例子**：
- 你伸手拿杯子，预测能顺利抓到 → 杯子突然被别人移动了 → 自由能升高（惊讶）
- 你相信"努力就有回报"，预测加班后会被表扬 → 实际被批评了 → 自由能升高

**大脑降低自由能的两条路径**：

| 路径 | 操作 | 例子 |
|------|------|------|
| **改变预测**（更新内部模型） | 修改你对世界的理解，让预测更准确 | 发现杯子常被移动 → 修改预测：伸手前先确认杯子位置 |
| **改变行动**（改变感官输入） | 主动行动，让现实符合预测 | 把杯子放回原位 → 继续伸手 → 成功抓到 |

**叙事语境下的理解**：
- **叙事 = 你的世界模型（内部预测系统）**
- 当叙事与现实不符 → 自由能升高（感到困惑、焦虑、受伤）
- 为了降低自由能，你需要**打磨叙事**

**打磨叙事的两种方式**：

| 方式 | 对应自由能路径 | 例子 |
|------|----------------|------|
| **知错而改** | 改变预测（更新模型） | 发现"老板会赏识努力的人"不成立 → 修改叙事："努力只是必要条件，还需展示成果" |
| **代偿/自洽** | 改变行动或调整预期 | 加班被批评 → 选择跳槽（改变行动），或告诉自己"这是磨炼"（调整预期） |

> 你必须经常打磨自己的各种叙事，让模型越来越准确。

**为什么"打磨"这个词好？**
- 打磨可以往多个方向：知错而改、代偿、自洽
- 不管往哪个方向，目的都是**降低自由能**
- 固执的人会在自由能升高时紧迫地打磨出一套勉强自洽的叙事，哪怕这套叙事并不准确，但能暂时压住惊讶带来的不适

##### 作用二：提供意义

**为什么小说容易入戏，说理文章费劲？**
- 小说有主人公、情感、意图
- 听到一个人的意图 → 自动关心他能否实现 → 就有了关心的方向

**价值观来源**：
- 想要出人头地 → 从小在给自己讲努力奋斗的故事
- 想要振兴中华 → 早就接受了这个叙事

##### 作用三：公共协作

**大规模合作的基础**（尤瓦尔·赫拉利的招牌学说）：
- 共同相信某些虚构的东西：神话、国家、货币、公司、法律
- 这些东西物理世界并不存在，纯粹是想象出来的叙事

**例子**：公司是什么？
- 不是厂房、机器、资本、工人、创始人
- 把这些都换掉公司还在
- 公司本质是虚拟概念，因为人们相信它存在它才存在

#### 1.6 叙事与行动

> 不要列举事实。要把事实穿起来形成叙事，你才能触发行动。

**关键洞见**：
> 我们从来都不是对一堆事实和数据做反应，我们是对叙事做反应。
> 我们不是根据事实做决策，我们是通过叙事做决策。

**例子**：
- 带兵打仗：只讲事实（敌军人数、地形、天气）→ 士兵一头雾水
- 说"此战关键是日落前封锁补给线" → 大家立即知道安排的意义，还能主动查漏补缺

**叙事经济学**（罗伯特·席勒，诺贝尔经济学奖）：
- 像病毒一般传播的叙事，是影响经济行为的核心变量
- 公司股价首先是信心的函数，信心来自对未来的叙事

#### 1.7 叙事的主观性

> 一切叙事都是主观的。

**证据**：
- 每时每刻周围有无数剧情上演，你为什么单单关注这个叙事？
- 同一个事实，可以选择不同的叙事方向

**例子**：
- 半瓶水：满了一半 vs 还有一半是空的
- 公司业绩好：必定继续扩张（股价会涨） vs 股价已很高（不要加仓）

**语言中的叙事选择**：
- 经济指标下降 → "负增长"
- 失业 → "待业" / "灵活就业"
- 正在经历的苦难 → "磨炼" / "奋斗" / "励志"
- 农民工找不到工作回家 → "返乡创业"

> 叙事决定了你的目标函数。

#### 1.8 叙事权：跳出与设定

**觉醒意识**：
> 跳出别人设定的叙事是现代人最根本的觉醒意识。

**电影《好东西》台词**：
> "怎么才能算好呢？裁判是谁啊？为什么就不能搞砸？又能砸到哪去呢？那我们不要玩他们的游戏了。"

**进阶**：
- 不但可以跳出别人的叙事
- 还可以给别人设定叙事 → **叙事权**（后面讲）

#### 1.9 总结定义

**叙事**是把一系列真实或者虚构的事物串起来的线索结构：
- 这根线索可以是：时间顺序、目标取向、命名定性、身份宣告、立场承诺
- 关键在于其中潜伏着**可验证的因果关系**
- 能**引导行动**和**校准情绪**

> 你能用到什么层次的工具取决于你讲给自己和讲给别人的叙事。

#### 1.10 万维钢的表达特点

**优点**：经常会蹦出一句特别有洞见的话

**不足**：有时用词别扭
- 例："预测处理"——不看解释无法理解，看完明白后觉得表达别扭
- 对比："提供意义"——顾名思义，容易理解

**洞见金句**：

1. **叙事不是因为「我」而存在，「我」是因为叙事而存在。**
2. **你一直都在给自己讲故事，你才有了意识。**
3. **不要列举事实。要把事实穿起来形成叙事，你才能触发行动。我们不是根据事实做决策，我们是通过叙事做决策。叙事是我们和世界交互的接口。**
4. **叙事决定了你的目标函数。**（对理工科的我来说这个表达太精当了！）
5. **跳出别人设定的叙事是现代人最根本的觉醒意识。**

#### 1.11 我的思考与启发

**关于"打磨叙事"的延伸理解**：

> 你必须经常打磨自己的各种叙事，让模型越来越准确。

- 大脑天然有降低自由能的诉求 → 潜意识驱使自己打磨叙事
- "打磨"这个词很好：可以包括所有方向的应对，可以是知错而改，可以是代偿，亦可以就只是为了自洽

**生活中的观察**：遇到否定、质疑与批评时，固执的人会紧迫地先为自己打磨出一套能勉强自洽的叙事，来避免"自由能"的溢出。

**文章表达线索**：叙事是什么？→ 因叙事而产生的自我 → 叙事的作用（行动的信念、方向、本身）→ 一切叙事都是主观的（可选择接受什么叙事）→ 还可以给别人设定叙事（叙事权）

### 第二条：重尾——世界服从极端值

#### 2.1 平均是假象

我们从小生活在"平均化"的小世界里——家里好吃的东西平分，同学用同样的课本、穿同样的校服，同事能力和收入差不多。长期在这种环境中，体感就是**人与人的差别不应该太大，平均才是正义**。

但真实世界一点都不平均：

- 最富有的1%人口拥有的财富，超过其余99%的总和
- 全球最富有的8个人的财富，超过排名靠后那一半人口的财富总和
- 少数公司占据行业大部分业务，少数明星拥有大部分粉丝，少数畅销书创造大多数销量

这就是**80/20法则**（帕累托法则）：20%的人口拥有80%的土地，20%的明星产品创造80%的收入……具体比例可能是10/90或1/99，关键是极端少数占据特别大的份额。

> 你在自己周围看不到，但这个世界的真相是它一点都不平均。它更倾向于极端。

#### 2.2 重尾分布

"极端少数占据大份额"的现象，在统计学上叫**重尾分布（heavy-tailed distribution）**，也叫**肥尾（fat tail）**。最典型的实现形式是**幂律（power law）分布**。

| | 正态分布 | 重尾分布 |
|--|----------|----------|
| **典型代表** | 身高、预期寿命、智商 | 财富、公司规模、名气 |
| **曲线形态** | 对称钟形，尾部短而薄 | 尾部肥大，极端值多 |
| **极值范围** | 有限（最矮1米多，最高不到3米） | 几乎无上限（财富可以差千倍万倍） |
| **平均值意义** | 有意义，多数人集中在均值附近 | 无意义，极端少数影响太大 |

> 你大可参照北京市居民平均身高找结婚对象，但你如果非得要求自己"另一半"的收入超过平均值，你会淘汰掉远超一半的人。

#### 2.3 正反馈与马太效应

造成重尾分布的核心机制是**正反馈过程**——"越大越容易变得更大"，即**马太效应**。

**马太效应**由社会学家**罗伯特·默顿（Robert K. Merton）**于**1968年**提出。他最初研究科学界的荣誉分配时发现：两个科学家合作完成一项研究，如果其中一位已很有名，另一位默默无闻，公众倾向于把功劳归给名人——即使两人贡献相当。他在论文 *"The Matthew Effect in Science"*（发表于《Science》期刊）中正式提出此概念。

名字取自《圣经·马太福音》第25章：

> 凡有的，还要加给他，叫他有余；凡没有的，连他所有的也要夺去。

**马太效应在各领域的表现**：

| 领域 | 正反馈机制 |
|------|------------|
| 财富 | 100万赚10万 vs 1万赚1千——同样的投资动作，收入差100倍 |
| 商业 | 大公司和小公司同样增长10%，绝对差距越拉越大 |
| 名气 | 已红的明星更容易获得优质资源，吸粉速度进一步加快 |
| 学术 | 明星科学家获得更多经费和合作机会，产出更多论文 |

#### 2.4 吉布拉特定律

由法国经济学家**罗伯特·吉布拉（Robert Gibrat）**于**1931年**在著作 *Les Inégalités économiques* 中提出。

**核心命题**：企业的增长率与其规模无关。大公司和小公司可以有相同的增长率。

**为什么导致重尾**：同样的增长率，基数大的人增量就大——

- 大公司规模1000亿，增长10% → 增加100亿
- 小公司规模1亿，增长10% → 增加1000万
- 绝对差距从999亿扩大到1098.9亿

**与马太效应的关系**：

| | 吉布拉特定律 | 马太效应 |
|--|-------------|----------|
| **性质** | 统计事实：增长率与规模无关 | 正反馈机制：越大越容易获得更多资源 |
| **含义** | 同样涨10%，差距必然拉大 | 大公司可能涨得更多 |
| **叠加效果** | 两者叠加，重尾分布更极端 | — |

**不符合吉布拉定律的行业**（规模不经济）：

核心特征是**生产要素无法标准化复制**的行业，公司大到一定程度后增长率反而下降：

| 行业 | 为什么规模不经济 |
|------|------------------|
| 创意/内容 | 创造力无法按人数线性放大，大机构流程和审批反而拖垮效率 |
| 专业服务（律所、咨询） | 依赖合伙人个人能力，协调成本随规模上升，顶尖人才易流失 |
| 软件开发 | 布鲁克斯定律：加人只会更慢（沟通路径随人数平方增长） |
| 教育/医疗 | 核心是人对人的服务，规模扩大意味着服务质量稀释 |
| 农业 | 土地是核心要素，边际产出递减 |

对比之下，符合吉布拉定律的行业（制造业、互联网平台、金融），核心生产要素是**资本、代码、网络效应**——可以无限复制和放大。

#### 2.5 乘法世界 vs 加法世界

正反馈的本质是**乘法**：

> 你的增量 = 你当前的动作 × 你的存量

- **乘法世界**：存量越大，增量越大，有复利。财富、机会、声望都属于乘法世界。
- **加法世界**：一天的劳动换一天的报酬，收入跟以前的积累无关，没有复利。

**加法世界的典型思维**：提高平均值，补齐短板——高考数学已经满分（150），最佳策略是补习英语；出租车司机每月只有30天能挣钱，最关心不要旷工。

**乘法世界的典型思维**：做方程中的乘数，只需要一块很长的长板——我们关心数学家的数学有多强，越强越好上不封顶，而不是他的英语有多弱。

> 加入重尾的秘诀是认准一个能让你做乘法的领域，实施正反馈。

**Sam Altman 的话**：

> 一般来说，最高的投资回报率来自于在你本来就擅长的领域变得更好，而不是在你薄弱的领域改进……大多数人过于关注自己的弱点。你希望在某个狭窄的交叉点上做到世界一流水准，而不是把一大堆事情做得比较好。

#### 2.6 乘法是双赢的

本能会觉得正反馈很不公平——难道回报不应该按劳动分配吗？但做乘法不只对被乘的富人有好处，对所有人都有好处：

- 你请超级明星带货，不是因为你喜欢她，而是因为她能最大化放大产品知名度
- 乘法效应是双向的，强强联手是多赢局面
- 如果你要开公司，你希望超级富豪投资；做科研，你希望顶级科学家合作

**劫富济贫的风险**：历史上劫富济贫的尝试几乎都以经济崩溃告终。托马斯·索维尔在《社会正义谬误》中列举了多个例子，如乌干达赶走亚洲企业家后经济崩溃。

#### 2.7 重尾不是永恒的

胜者通吃的副产品是贫富差距拉大，但问题没有想象的那么严重：

- 明星不会一直红（人们会厌烦，自己会变老，跟不上变化）
- 大公司不会永葆青春（产业衰退，错过创新被颠覆）
- 历史上没有永远的富人，财富会被子孙后代迅速败光
- 纵向数据看，年轻时贫困的人多数在成年后收入显著提高；曾经特别有钱的人排位也可能跌落

**减少富人财富的途径**：投资失败、代际稀释、离婚解体、税收和通货膨胀。富人投资暴雷是大自然调节贫富差距最快的手段。

> 贫富差距的确是问题，但如果这就是乘法世界的代价，我们宁可支付这个代价也不能取消乘法。有人飞得高不可怕，整个气流停了才可怕。

#### 2.8 风险投资的乘法策略

风投是明显的重尾事业：约10%的投资退出贡献了85%的现金回报。

**"10%退出贡献85%回报"怎么理解**：一个风投基金投了100家公司，大部分是亏的或持平的，少数小赚，极少数是超级赢家——这1-2家赚的钱，占了整个基金所有回报的85%。所以风投行业不服从平均值，真正决定基金业绩的就是那1-2笔超级投资。

具体数字推演：假设投了10家公司，每家投1000万——7家失败打水漂，2家小赚各2000万，1家爆发赚1.7亿。总回报2.1亿中，那1家爆发公司占81%。

但秘诀不是广撒网——而是**选择时机追加投资**，跟着公司正反馈成长。因为整个基金的回报几乎就靠那1-2家超级赢家，所以一旦发现某家公司有超级赢家的潜质，必须加重押注。投资人最看中的权益是**按比例认购权（pro rata rights）**，保证在公司后续融资时持股比例不被稀释，从而能跟着正反馈一路追投。

> 乘法世界要求你不能平均地对待每个合作对象，你必须谋求跟"大乘数"互相促进共同成长。

#### 2.9 正反馈的阴暗面

正反馈不总是好事：

- 病毒和恐慌情绪的传染是正反馈
- 金融风暴、飓风和地震是复杂系统级联正反馈
- 塔勒布的"黑天鹅"事件也是重尾上的极端事件

**黑天鹅与重尾**：人们习惯用正态分布的直觉去预判世界，认为极端事件"几乎不可能发生"，可以忽略尾部风险。但真实世界是重尾分布的——尾部事件虽然概率低，却远比正态分布预测的要频繁，一旦发生影响是灾难级的。黑天鹅不是"不可能发生的事发生了"，而是"你以为世界是正态分布，但世界其实是重尾分布——尾巴上的极端事件，比你以为的频繁得多、猛烈得多"。

**边际递减才是规律，持续正反馈只是暂时的**：万维钢提到"也许除了目前为止的计算机芯片摩尔定律和AI的缩放定律之外——都不会永远按固定比例增长"，加了"目前为止"这个限定。事实上摩尔定律已在放缓——晶体管微缩逼近物理极限（3nm，硅原子直径约0.2nm），翻倍周期从2年延长到2.5-3年，算力增长的驱动力已从晶体管微缩转向架构创新和专用芯片。AI缩放定律（2020年OpenAI发现：模型性能随参数量、数据量、计算量呈幂律提升）目前尚未触顶，但能持续多久是行业最大争议。这些"例外"反而印证了：没有哪个正反馈能永远逃脱边际递减，区别只在于时间尺度的长短——带货明星几年到十几年审美疲劳，大公司几十年被颠覆，摩尔定律半个世纪逼近极限。不是对抗递减，而是在递减到来之前切换轨道，开发**第二曲线**。

身处重尾世界不能光想着发达，得先保本——需要理解**脆弱与反脆弱**。

#### 2.10 个人行动指引

> 作为重尾世界中的普通人，我会设法加入到乘法世界中去。

- 希望和资本、网络效应、声望联系起来
- 避免那些"做一件事得一份钱、跟存量没关系"的工作
- 希望以往的成就能影响以后的机会
- 希望建立个人信誉和品牌，积累复利，形成正反馈

**选择行业的启示**：进入哪个行业决定了你在加法世界还是乘法世界。如果行业天然存在规模不经济，"做大"未必是正确策略，"做精"反而是长板。

### 第三条：能动——稳态生存的观念陷阱

#### 3.1 思想实验：《人生说明书》

**设定**：你功成名就、垂垂老矣，即将转世投胎到中国，但投胎完全随机——大概率是普通甚至贫困家庭。你无法储备财富，知识和技能都会被忘掉。唯一特权：可以给下一世的自己写一份《人生说明书》。

**你会写什么？** 万维钢的回答：
- 尽快前往大城市
- 掌握可迁移技能，争取不对称优势，积累复利
- 理解重尾分布，加入乘法世界
- **最必须写的内容**：摆脱平庸观念的束缚

> 你周围的人，你的同学、老师，包括你的父母，都认为这些观念是天经地义的。可是殊不知那些人人都在用的梯子，多半只能到达人人能到的高度。

#### 3.2 稳态生存逻辑：三大基因

**文化滞后（Cultural lag）**：文化观念的更新总是比物质条件的改变慢很多。世界已经变了，但人的观念不会及时升级。

稳态生存逻辑有三大基因：

| 基因 | 核心逻辑 | 衍生现象 |
|------|----------|----------|
| **资源匮乏** | 专注求生存，顾不上求发展 | 次级奖励、人情、零和思维、风险厌恶 |
| **强从众** | 安全感来自人际关系而非法律 | 顺从价值观、态度文化、面子文化 |
| **简单思维模型** | 把外部世界当成一个整体 | 线性思维（努力）、指标主义 |

> 适应匮乏、强从众和简单模型对稳态生存来说不但够用，而且好用。那些品质常常是很好的局部理性，但是从全局来看，却是把人困在陷阱里的枷锁。

#### 3.3 基因一：资源匮乏

**核心机制**：匮乏让人把生存策略上升为价值观、道德乃至于审美——而且当事人不认为那是不得已，因为从来就没考虑过还有别的可能性。

**次级奖励（secondary rewards）**（霍夫曼 & 约耶里，《隐藏的博弈》）：你本来不喜欢这东西，是通过学习，才喜欢。

| 案例 | 原始原因 | 美化后的叙事 |
|------|----------|--------------|
| 韩国泡菜、英国炸鱼薯条、美国 potluck | 困难时期廉价果腹方法 | 民族特色，需要传承的文化 |
| 日本侘寂（Wabi-sabi） | 物资匮乏，东西坏了凑合用 | 对残缺的美学追求 |

**匮乏的连锁效应**：

1. **人情**——无力购买服务，必须邻里互助，默默记下人情债
2. **孝道**——以情感绑架为手段的养老保险。有了养老金后，父母独立性提高，与子女关系反而更纯粹（Chen 2017; Daatland & Lowenstein 2005）
3. **零和思维**——资源就这么多，你多拿我就少点→贫穷代表道德，富人都是坏人
4. **风险厌恶**——只有一千元时，不确定性是敌人；有一百万时，不确定性才是朋友

> 匮乏对头脑最深的影响，是「风险厌恶」。

**风险厌恶与筹码的关系**：你和不确定性的关系，取决于你手里有多少筹码。只有一千时亏掉就真没了，不确定性意味着生存威胁；有一百万时拿十分之一试错，不确定性意味着机会。匮乏最深的伤害不是让你穷，而是让你不敢试——而重尾世界里，不试就永远在加法世界。这跟第二条"重尾"形成残酷闭环：**穷→风险厌恶→不敢进入乘法世界→更穷**。

**风险厌恶作为最根深蒂固的文化滞后**：

| 时代需求 | 旧观念 | 恐惧根源 |
|----------|--------|----------|
| 注意力稀缺，要善于表现自己 | "枪打出头鸟"，要求低调 | 怕被嫉妒 |
| 最小可行产品（MVP），快速迭代 | 万事俱备才行动 | 怕失败 |

#### 3.4 基因二：强从众

**万维钢的论证**：强从众是因为弱规则。

- 强规则社会：只要不违反规则就可以干，理直气壮地个性化发挥
- 弱规则社会：法律不能给你当挡箭牌，不知道做什么事会得罪什么人，最安全的办法就是照着大多数人那样做

**从强从众推出的衍生现象**：

| 衍生现象 | 逻辑 |
|----------|------|
| **顺从价值观** | 安全感来自人际关系→自动服从权威→"听话"被当优点 |
| **态度文化** | 服从是一种业绩→态度就成了能力，姿势就成了成果→以忙碌为荣，无效忙碌 |
| **面子文化** | 决定做什么先考虑别人怎么看→别人都买房你也买，看似上进实为从众 |

> 那个从小被你夸听话的孩子，搞不好就成了假装学习、无效忙碌、逼着你给他拿结婚彩礼钱的孩子。

#### 3.5 基因二论证链条的质疑与修正

万维钢从弱规则推出强从众，再从强从众推出面子和态度文化，但这条论证链存在断裂。

**断裂点**：面子和态度文化的真正驱动力，是**他人评价决定资源分配**——在密集人际网络中，被认可才能获得机会，被排斥就寸步难行。这跟规则强弱没有必然关系。一个强规则社会里的小圈子（比如大公司内部）照样可以有面子文化和态度文化——法律保护你不被违法侵害，但保护不了你在小圈子里被边缘化。

**更干净的逻辑链**：

```
匮乏 → 人际网络是生存保障 → 偏离群体=失去资源 → 强从众 → 面子文化/态度文化
```

弱规则可以作为独立的加速因素（让法律没法给你兜底，更依赖人际关系），但不是这条链的必要条件。

**弱规则不是从众的唯一根因**：

| 驱动力 | 机制 | 与弱规则的关系 |
|--------|------|----------------|
| **进化本能** | 灵长类群居动物天生服从群体，被排斥≈死亡，预装在基因里 | 无关 |
| **信息从众** | 不确定时看别人怎么做，是认知捷径 | 无关，跟信息不对称有关 |
| **归属需求** | 从众是最低成本的社交货币，满足情感需求 | 无关 |
| **弱规则** | 法律不能兜底→更依赖人际关系→从众变成强制 | 放大器 |

> 弱规则更像是从众的放大器，让从众从"倾向"变成了"强制"，但不是唯一的根。

这一讲没有区分从众与强从众的差别，容易让读者误以为弱规则是从众的主因。

#### 3.6 基因三：简单思维模型

**典型例子**：同事借8000元，只还7992元——因为微信提现扣了8元手续费。把外部世界当成一个整体：我从世界拿到了7992元，所以还回去7992元。不能理解借钱是同事之间的信用关系，手续费是微信的事。

**线性思维："努力"**

- 家长让孩子努力、领导让员工努力——可是往哪个方向？怎么努力才有效？
- 单纯的努力 = 把外部世界当成一个整体，以为有个神灵看你努力就给你发奖励
- 必须有更复杂的模型，才知道该做什么选择、在哪个领域、有没有杠杆、时机如何

**中国足球的类比**：

骂球员不努力、没有拼搏精神，希望看到"纯粹的足球"，是渴望让世界变简单——桃花源情结。业余联赛可以纯粹（只有热爱），但职业足球是一个**产业系统**：青训体系、俱乐部治理、联赛机制、商业运营、行政环境、腐败风险……中国足球的问题不是球员不努力（同样球员去欧洲联赛表现可以不同），而是**系统问题**。

把系统问题简化为态度问题，正是"简单思维模型"的典型表现——跟"努力"是线性思维一脉相承。

**指标主义**：一切为了达成某个指标→学习是为了考成绩→"课外书"没有指标→考上985就得拿高薪，考上公务员就得稳定升职→只知道世界欠我的，不知道自己能给世界提供什么。

#### 3.7 稳态生存逻辑的"好用"与枷锁

从小听话、节俭、努力、随大流、不出头、又孝又顺的人——地主希望佃农如此，店主希望服务员如此，勉强糊口的家长认为子女任何个性发挥都是制造麻烦。

> 别人期待你省心，肯干，不闯祸——别人可没期待你兴旺发达。官办学校从来不是教人赚钱的地方，那是训练合格劳动者和守法居民的地方。

#### 3.8 结论：能动者（Agent）

> 真正爱孩子的家长应该希望孩子不要那么听话、不必过于努力、不用害怕群体压力，甚至敢去创造一点波动。

**前提**：你得是个**能动者（Agent）**——你是调用工具的人，你不能是别人的工具。

**为什么是 Agent？** 哲学传统中 Agent 的核心含义是"有能动性的主体"——行动的发起者，有自主意志，能做选择。与之相对的是 Patient（被行动的对象、承受者）。这讲的核心对比正是：你是 Agent（调用工具的人）还是 Patient（别人的工具）。中文"能动"也有渊源——马克思主义哲学讲"主观能动性"，人作为主体对世界的主动把握和改造，跟 Agent/agency 是同一个思想谱系。

AI 领域管自主系统叫 Agent，也是同一个哲学根：自主感知环境、做决策、采取行动，而不是被动等指令。万维钢选这个英文词，是把人放在和 AI Agent 同等的位置上——你应当是一个自主运行的系统，而不是被别人调用的 API。

#### 3.9 万维钢的论证方式

**开局手法**：思想实验（《人生说明书》）——把抽象的"摆脱观念束缚"变成一个具体的、有代入感的场景。

**论证结构**：三大基因平铺展开，每个基因先给核心逻辑，再铺排衍生现象，用日常案例佐证。这是"从根推果"的演绎式结构。

**收束**：三大基因在稳态生存中"好用"→但从全局看是枷锁→结论是做能动者。用一首诗收束，把理性论证收拢到感性共鸣。

**不足**：
- 三大基因之间的相互关系未充分展开（匮乏和强从众实际上互相喂养，而非独立并列）
- 强从众的论证链条存在断裂（见 3.5）
- 没有区分从众与强从众，容易造成阅读误解

#### 3.10 洞见金句

1. **你周围的人认为天经地义的观念，那些人人都在用的梯子，多半只能到达人人能到的高度。**
2. **匮乏对头脑最深的影响，是风险厌恶。**（与第二条"重尾"形成残酷闭环：穷→风险厌恶→不敢进入乘法世界→更穷）
3. **如果服从是一种业绩，态度就成了能力，姿势就成了成果。**
4. **别人期待你省心，肯干，不闯祸——别人可没期待你兴旺发达。**
5. **你得是个能动者（Agent），你是调用工具的人。你不能是别人的工具。官办学校从来不是教人赚钱的地方，那是训练合格劳动者和守法居民的地方。
6. **弱规则更像是从众的放大器，让从众从"倾向"变成了"强制"，但不是唯一的根。**（讨论修正）
7. 古律如锁，锁住饥寒与不安；钥匙早已生锈——你却把它挂在胸前，当作信仰的徽章。

#### 3.11 我的思考与启发

**关于"风险厌恶"与重尾的闭环**：匮乏导致风险厌恶，风险厌恶让人不敢进入乘法世界，留在加法世界又加剧匮乏——这跟第二条"重尾"的洞见形成了呼应。万维钢把两条世界观分开发布，但读者应该把它们连起来看：重尾描述了世界是什么样，能动描述了是什么在阻止你进入那个世界。

**关于强从众论证链条的断裂**：万维钢把匮乏和强从众列为两大独立基因，但它们其实互相喂养——匮乏让人依赖人际网络，依赖人际网络就催生强从众。更干净的框架或许是：匮乏是根，强从众和简单模型是从匮乏长出来的枝，弱规则是一个独立的加速因素。

**关于"能动"与 AI Agent**：当 AI 被称为 Agent 时，它的"能动性"来自人类设定的目标函数；人的能动性则来自自我设定的叙事（呼应第一条"叙事"）。做 Agent 不只是"主动"，更是**自己选择自己的目标函数**——这正是"跳出别人设定的叙事"的含义。

### 第四条：约束——先尊重，再行动

#### 4.1 这一讲的核心问题

第一讲说「叙事」是人理解世界、触发行动的接口，但叙事有一个危险：它很容易滑向许愿、神话和爽文。

这一讲要解决的问题是：**什么样的叙事才是有效的？**

答案是：

> 有效的叙事一定是在各种硬约束的范围之内找出路，而不是把世界当成愿望实现机。

所以这一讲不是在否定叙事，也不是在否定梦想，而是在给叙事加上现实校准器：

```
叙事负责激发行动
约束负责校准行动
成熟行动 = 在硬约束内寻找可行路径
```

#### 4.2 从小说六层看「许愿型叙事」

万维钢先把流行小说按「一厢情愿程度」分成六层：

| 层次 | 类型 | 神话本质 | 代表作品 |
|------|------|----------|----------|
| 第一层 | 系统外挂 | 什么都不用付出，就被选中、一夜逆袭 | 神笔马良、漫威、哈利·波特开头 |
| 第二层 | 霸道总裁爱上我 | 被动善良就能被强者看见、被命运奖赏 | 灰姑娘、聊斋、简·奥斯汀式爱情 |
| 第三层 | 金庸武侠 | 不主动争名利，只要不忘初心，荣华富贵自然来 | 郭靖、令狐冲、萧峰、段誉、虚竹 |
| 第四层 | 升级打怪 | 努力一定升级，支付代价一定有回报 | 现代网络小说 |
| 第五层 | 对抗体制 | 世界残酷，但至少好坏分明，可以选择正义一方 | 冰与火之歌、红楼梦 |
| 第六层 | 寻找意义 | 没有绝对好坏和对错，只能在无奈中寻找意义 | 活着、1984、美丽新世界 |

这一段表面是文学分类，实质是在拆解人的行动幻想。

很多人不是只在小说里做梦，在生活中也用类似爽文结构理解世界：

- 我这么努力，公司总该看见我吧
- 我这么善良，命运总该奖励我吧
- 我初心这么好，事情自然会成吧
- 只要我足够拼，就一定能升级吧
- 如果失败了，一定是有人故意挡我吧

这类叙事的共同问题是：**把现实世界理解成一个会按主角意愿发放奖励的系统。**

> 大多数人的生活叙事其实是许愿。

#### 4.3 什么是硬约束？

现实和想象最大的区别，是现实中有大量「硬约束」。

**硬约束**不是普通困难，而是无法绕开的边界条件。困难可以靠努力克服，但硬约束必须先被承认、被计算、被纳入模型。

常见硬约束包括：

- 预算只有这么多
- 一天只有 24 小时
- 人会累，组织会内耗
- 法律程序不能跳过
- 市场不会因为你的初心而买单
- 别人有自己的利益、判断和反应
- 物理、经济、组织、人性都有自己的规律

硬约束不是「有人针对我」，而是：

> 世界本身有边界条件。

所以万维钢在马斯克 DOGE 案例里说：

> 你总不能说加法运算是你的敌人。

这句话的意思是，有些事情不是谁在挡你，而是账本本来就不支持。

#### 4.4 开牛排店：从单点能力到系统现实

文章用开牛排店说明：想象中你面对的是一个「做牛排」问题，现实中你面对的是一个「经营系统」问题。

```
想象中：我会做很好吃的牛排 → 我能开好牛排店
现实中：开店 = 供应链 + 设备 + 产能 + 定价 + 合规 + 服务 + 现金流
```

具体约束包括：

- 采购约束：每天凌晨抢肉，冷链车还可能堵在早高峰
- 设备约束：精准火候可能需要定制炉子
- 产能约束：晚高峰前能不能完成大量订单
- 定价约束：顾客是否愿意为你的品质付费
- 合规约束：消防、卫生检查
- 服务约束：挑剔顾客、投诉、员工管理

这一段的关键洞见：

> 你以为自己面对的是一个烹饪问题，现实中你面对的是一个经营系统问题。

这也呼应第三讲「能动」里的简单思维模型：人容易把复杂系统压缩成单一变量。第四讲进一步说明，简单模型之所以错，是因为它没把约束条件纳入模型。

#### 4.5 DOGE 案例：越大的事，硬约束越多

马斯克和特朗普的政府效率部（DOGE）案例，是这一讲最重要的现实例子。

他们的叙事很像爽文：

```
天命总统 + 伟大企业家 + 天才少年 + 睡办公室拼命干
→ 根治政府腐败
→ 每年省 2 万亿美元
→ 给老百姓返钱
```

但预算账一算，叙事就站不住了：

| 项目 | 占比 | 约束 |
|------|------|------|
| 医保、社保等法定支出 | 超过 60% | 不能随便动，需修改法律 |
| 债务利息 | 13% | 必须支付 |
| 可自由裁量部分 | 27% | 总统和国会真正能动的钱 |
| 军费 | 约 13% | 马斯克惹不起 |
| 真正能触碰部分 | 约 14%，不到 1 万亿 | 目标却是省 2 万亿 |

核心问题：

> 你怎么从不到 1 万亿的可动空间里，省出 2 万亿？

这说明：

> 宏大叙事最怕算账。

这不是说政府不需要改革，也不是说马斯克不聪明，而是说即使是强人、天才、权力中心，也不能绕过预算结构、法律程序、利益关系和组织运行这些硬约束。

> 事儿越大，硬约束就越多，自由发挥的空间就越小。

#### 4.6 四种无法逃避的硬约束

万维钢给出四种最底层的硬约束。

##### 4.6.1 能量守恒

做任何事都要消耗资源，资源不会凭空出现。

这里的「能量」不只是物理能量，也包括：

- 钱
- 时间
- 注意力
- 体力
- 情绪能量
- 人力
- 信息
- 信任
- 组织资源
- 政治资本

对应的行动问题是：

> 我手里到底有什么资源？这些资源够不够支撑这个行动？

很多幻想的错误，是假设行动不消耗资源：想创业但不算现金流，想学习但不算时间精力，想改革组织但不算沟通成本和阻力。

##### 4.6.2 时间窗口

很多事情不是任何时候都能做。窗口期到了，约束会暂时放松；窗口期没到，你只能等；窗口期过去，再努力也很难。

例子：

- 行业红利期
- 产品进入市场的时机
- 投资估值周期
- 职业转型的年龄、精力和家庭阶段
- 一段关系的修复窗口
- 政策周期和组织变革窗口

对应的行动问题是：

> 现在是窗口期、等待期，还是窗口已经关闭？

##### 4.6.3 自然规律

事物有自身的发展规律，不因为你的意志、热情、道德感而改变。

这里的规律可以是：

- 物理规律
- 生理规律
- 经济规律
- 组织规律
- 学习规律
- 传播规律
- 复杂系统规律

例子：

- 人不能长期睡四小时还保持高效
- 用户不会因为你觉得产品好就付费
- 组织规模变大后沟通成本必然上升
- 学习需要反馈和间隔重复，不是听一遍就会
- 减肥需要热量缺口，不是靠意志喊口号

对应的行动问题是：

> 这件事背后的规律是什么？我有没有逆规律而行？

##### 4.6.4 他人的能动性

别人不是 NPC，不会按你的剧本行动。每个人都有自己的目标、利益、情绪、判断和反应。

例子：

- 你以为领导会赏识你，但领导有自己的 KPI
- 你以为用户会喜欢产品，但用户有自己的习惯
- 你以为伴侣会理解你，但伴侣也有自己的委屈
- 你以为员工会执行命令，但员工会计算风险收益
- 你以为竞争对手会静止不动，但对方也会反击
- 你以为孩子会按你的规划成长，但孩子也有自己的能动性

对应的行动问题是：

> 这件事中其他参与者会怎么反应？他们的目标函数是什么？

这条和第三讲「能动」联系最强：第三讲说你要成为能动者，第四讲补充说别人也是能动者。

#### 4.7 算账：识别硬约束的基本方法

考虑硬约束最简单的方法就是算账。很多美好设想，只要算一算账，就知道不可能。

但这里的「算账」不是第五种约束，而是识别四种硬约束的方法：

| 硬约束 | 要算什么账 |
|--------|------------|
| 能量守恒 | 资源账：钱、时间、精力、组织资源、信任是否足够 |
| 时间窗口 | 时机账：现在是窗口期、等待期，还是窗口已经关闭 |
| 自然规律 | 规律账：这件事的物理、经济、组织、学习规律是否支持 |
| 他人的能动性 | 反应账：其他参与者会如何理解、选择和反击 |

地底文明的例子说明了「算账」的力量：

```
文明水平
  依赖创新能力
    依赖分工复杂度
      依赖人口规模
        依赖食物供给
          依赖可用能量
```

地表文明的能源本质上来自太阳，而地底没有阳光，只能依靠地热。地热通量远小于太阳能输入，能量少就意味着食物少，食物少限制人口规模，人口规模限制分工复杂度，分工复杂度又限制创新能力。

所以，如果地底真有文明，也很难支撑出比地表更高级的科技文明。

这一段的方法论意义是：

> 不要先问故事好不好听，先问账算不算得通。

#### 4.8 约束为什么是好消息？

对不成熟的人来说，约束是坏消息，因为它意味着不能随心所欲。

但对成熟的人来说，约束其实是好消息。

因为如果世界没有约束，就意味着：

- 没有规律
- 没有可预期性
- 没有方法论
- 没有安全感
- 强者也可以随心所欲
- 努力无法校准

有约束，世界才有章法：

- 你不能为所欲为，别人也不能为所欲为
- 你受预算限制，别人也受预算限制
- 你受时间限制，别人也受时间限制
- 你不能无成本行动，别人也不能无成本行动

所以约束不是单方面压迫你，而是给所有行动者共同设定边界。

> 有约束才可预期，才讲章法，才值得研究和学习。

#### 4.9 和前三条世界观的关系

前四条世界观可以形成一条递进线索：

```
叙事：你需要一个故事来理解世界并触发行动
  ↓
重尾：但真实世界不是平均奖励系统，而是乘法、复利和极端值主导的世界
  ↓
能动：所以你不能只做被环境调用的工具，要成为主动选择目标函数的 Agent
  ↓
约束：但主动不是许愿，行动必须在硬约束内求解
```

所以「约束」不是在否定「能动」，而是在给能动性加边界。

如果只讲能动，容易滑向热血鸡汤：我要主动，我要改变命运。

如果只讲约束，容易滑向犬儒：现实太难，算了。

两讲合起来才完整：

> 能动性 = 在约束内寻找杠杆，而不是幻想没有约束。

#### 4.10 行动前检查表

这一讲可以转化为一个行动前检查表。

不要只问：

- 我想要什么？
- 我的初心是什么？
- 我有没有足够努力？
- 这个故事是不是激动人心？

而要先问：

| 检查项 | 问题 |
|--------|------|
| 资源 | 我能调动什么？资源够不够支撑这个行动？ |
| 时间 | 现在是窗口期、等待期，还是窗口已过？ |
| 规律 | 这件事背后的规律是什么？我是否逆规律而行？ |
| 他人 | 其他参与者会怎么反应？他们的目标函数是什么？ |

所谓「算账」，就是把这四个维度逐一盘清楚。如果这些问题没过，叙事再漂亮也是许愿。

#### 4.11 洞见金句

1. **现实和想象最大的区别，是这里有大量的「硬约束」。**
2. **触碰到资源的边界你就遭遇硬约束，遭遇硬约束才明白以前想的是神话。**
3. **事儿越大，硬约束就越多，自由发挥的空间就越小。**
4. **你总不能说加法运算是你的敌人。**
5. **你必须尊重硬约束，你得把你那个世界模型中的硬约束想清楚，划好边界条件，再谈成事的路径。**
6. **你不能假设别人都是 NPC，只想自己做主角。**
7. **宏大叙事最怕算账。**
8. **有效的叙事一定是在各种硬约束的范围之内找出路，而不是把世界当成愿望实现机。**
9. **有约束才可预期，才讲章法，才值得研究和学习。**
10. **我们可以自由选择行动，但不能自由选择行动引起的走向。**

### 第五条：可能——不确定性是意义的燃料

#### 5.1 这一讲的核心问题

前四条世界观已经形成了一条行动线索：

```
叙事：人需要故事来理解世界并触发行动
  ↓
重尾：真实世界不是平均奖励系统，而是极端值和乘法效应主导
  ↓
能动：所以人要成为 Agent，而不是被环境调用的工具
  ↓
约束：但能动不是许愿，行动必须尊重硬约束
```

第五条「可能」接着回答一个更底层的问题：**即使我们尊重了约束，世界是否就可以被稳定预测？**

答案是否定的。

> 世界不会给你绝对确定，反而靠不确定性生成意义；不要只求稳定，要学会管理、拥抱，甚至利用不确定性。

这一讲不是简单说「世界很随机」，而是在建立一个新的世界观：

> 不确定性不是一个暂时没解决的问题，而是世界运行的基本结构。

#### 5.2 五种不确定性：追求确定性的失败路径

万维钢列出五种不可避免的不确定性。它们表面上是并列的，但更有意思的理解是：它们构成了一条递进链条——**人类每想出一种消除不确定性的办法，下一层不确定性就会让这个办法失效。**

可以把这五种不确定性理解为五道防线：

```
测量信心 → 计算信心 → 决定论信心 → 概率模型信心 → 预言信心
   ↓          ↓            ↓              ↓              ↓
混沌       计算不可约性    量子随机        奈特不确定性    反身性
```

##### 第一层：混沌——你以为问题是「测得不够准」

**混沌（chaos）**指复杂系统对初始条件极端敏感。天气就是典型例子：初始温度、气压、湿度、风速只要有极小误差，几天之后的结果就可能完全不同。

混沌击穿的是「测量信心」：

> 你以为只要把初始条件测得足够准确，就能预测未来；混沌说，只要误差不为零，它就会被迅速放大。

这一层的关键词是：**测不准**。

注意这里的「测不准」不是量子意义上的测不准，而是复杂系统意义上的：我们无法把初始条件测到绝对精确，而微小误差会被系统放大。

##### 第二层：计算不可约性——你以为测准了就能「算出来」

如果没有测量误差，初始条件和规则都完全清楚，是不是就能预测未来？

**计算不可约性（Computational Irreducibility）**说：未必。有些系统没有比「让它自己一步步运行」更快的捷径。你想知道它第 10000 步是什么样，最可靠的办法就是从第 1 步算到第 10000 步。

这就是所谓的「算不快」。它不是说电脑性能不够，而是说：

> 有些结果不能被压缩成一个更短的公式；预测它，和运行它本身，复杂度差不多。

生命游戏（Conway's Game of Life）是典型例子。它的规则极其简单：二维格子里每个格子只有「活」或「死」两种状态，每一轮根据周围 8 个格子的状态决定下一轮生死。但这样简单的规则可以产生稳定、震荡、移动、碰撞，甚至能模拟计算机的复杂图案。很多时候你想知道第 1000 步是什么样，只能一代一代跑出来。

图灵机停机问题则是更极端的例子：不存在一个万能算法，可以判断任意程序在任意输入下最终会不会停止。某些程序你不能事先判断它会不会运行完，只能运行看看；如果它一直没停，你也不知道它是真的永远不停，还是只是还没运行到停止的那一步。

计算不可约性击穿的是「计算信心」：

> 你以为知道规则就能提前算出未来；计算不可约性说，有些未来不是藏在公式里等你发现，而是在演化过程中一步步生成的。

这一层的关键词是：**算不快**。

更好的表达是：

> 你不能跳过过程直接拿结果，因为结果本身就是过程生成的。

##### 第三层：量子随机——你以为算不快只是能力问题

到这里，人还可以安慰自己：虽然我算不快，但未来本身也许还是确定的，只是我没有能力提前知道。

**量子随机**击穿了这个安慰。按照主流量子力学解释，有些事件在发生之前，并不是已经有一个隐藏答案等你发现，而是本身就是概率性的。比如某个原子核下一秒是否衰变，电子会落在屏幕左边还是右边。

量子随机击穿的是「决定论信心」：

> 不是你不知道，而是世界在某些底层事件上本来就没有确定答案。

这一层的关键词是：**天生随机**。

前两层还可以说是认知限制：我测不准、算不快。量子随机则把问题推进到本体层面：有些未来不是人类不知道，而是世界本身还没有确定下来。

##### 第四层：奈特不确定性——你以为有概率就可以管理

面对随机性，人还可以退一步：我不追求确定，只要知道概率分布，也能管理不确定性，比如保险、投资组合和风险控制。

**奈特不确定性（Knightian uncertainty）**说：有时候你连概率空间都不知道。

风险是「已知可能结果集合中的随机性」：比如骰子有六面，我不知道会掷到哪一面，但知道有哪些面。奈特不确定性则是：你以为骰子有六面，结果游戏本身变了。

比如预测一家头部手机品牌五年后的竞争力，如果未来仍然是手机市场竞争，你可以估计它继续领先的概率。但如果五年后出现一种完全不同的通信设备，人们干脆不再使用手机，原来的模型就失效了。那个变量根本不在你的模型里，也就无从计算概率。

奈特不确定性击穿的是「概率模型信心」：

> 你以为知道可能结果和概率分布就能管理未来；奈特不确定性说，真正关键的变量可能根本不在你的模型里。

这一层的关键词是：**想不到**，或者说：**概率空间之外**。

##### 第五层：博弈不确定性 / 反身性——你以为有人剧透就行

如果问题是模型外会冒出新变量，那如果有一个时间穿越者回来告诉你未来呢？

**博弈不确定性**，也叫**反身性（reflexivity）**，堵上了这个最后的漏洞。

在人类社会里，预测一旦被说出来，就会改变被预测的未来。比如有人穿越回来告诉大家：2030 年 9 月 6 日全球股市会崩盘。股民不会等到那天才卖，而是提前行动；他们的提前行动会改变崩盘何时发生，甚至是否发生。

反身性击穿的是「预言信心」：

> 你以为只要有人提前剧透未来，就能获得确定性；反身性说，剧透本身会进入系统，成为改变未来的新变量。

这一层的关键词是：**一说就变**。

#### 5.3 五种不确定性的递进表达

这五种不确定性可以讲成一组连续问答：

```
1. 如果我测得足够准，能不能预测？
   —— 混沌说：不行，微小误差会被放大。

2. 如果我没有测量误差，能不能预测？
   —— 计算不可约性说：不行，有些系统只能一步步运行。

3. 如果我有无限算力，能不能预测？
   —— 量子随机说：不行，有些事件本身没有确定答案。

4. 如果我用概率管理随机性，能不能预测？
   —— 奈特不确定性说：不行，有些变量根本不在你的概率空间里。

5. 如果我让未来人直接告诉我答案，能不能预测？
   —— 反身性说：不行，答案一旦被说出，就会改变未来。
```

更精炼的讲法：

> 人类追求确定性，就像一层一层往下打补丁：先想测准，再想算快，再想用概率，再想扩大模型，再想提前剧透未来。可每下一层，都会遇到一种更顽固的不确定性。

这条递进链条说明：

> 世界不是一个等待你完全破解的静态谜题，而是一个不断生成新可能性的动态过程。

#### 5.4 不确定性带来运气：成功不能只归因于能力

前面证明不确定性不可消除，接下来文章转向成功和财富：世界财富呈重尾分布，极少数人拥有远超多数人的财富；但人的智商和能力大体呈正态分布，差距没有财富差距那么极端。

这就提出一个问题：如果能力差距没那么大，结果差距为什么这么大？

万维钢引用罗伯特·弗兰克《成功与运气》和 2018 年意大利科学家的模拟实验说明：当能力呈正态分布，而人生中不断遭遇随机的幸运和不幸事件时，最终财富会呈现重尾分布。最富有的人不是最有能力的人，而是能力不错、又遇到最多幸运事件的人。

结论不是否定能力，而是重新定位能力：

> 运气决定你会遇到什么，能力决定你如何响应。

极端成功往往来自：

```
不错的能力 × 好运气 × 正反馈
```

所以不确定性不只是风险，也是机会和运气的来源。没有不确定性，就没有正面意外，也没有人生跃迁。

#### 5.5 面对不确定性的三种态度

##### 第一种消极态度：渴望确定性

人在失控时会渴望确定感。越缺乏控制感，就越需要一个强人、神灵、制度或权威替自己掌舵。这叫**补偿性控制（Compensatory Control）**。

这种心理会被权力利用：先夸大世界的不确定性，再承诺提供确定感——外面的世界很危险，只有跟着我才安全。

> 谁提供确定感谁就得到权力，谁渴望确定感谁就把权力让给别人。

对确定性的过度渴望，会让人交出主动性。

##### 第二种消极态度：只是接受不确定性

比渴望确定性好一点的态度，是「允许一切发生」「凡事发生皆有利于我」「一切都是最好的安排」。

但如果把一切都解释成最好的安排，也可能变成放弃主动性：别人怎么安排你都行。

所以接受不确定性不等于躺平。

##### 积极态度：管理、拥抱、制造不确定性

真正积极的态度是：

> 合理分析不同类型的不确定性，坏的我想办法管理，好的我积极拥抱。

塔勒布的《黑天鹅》提醒我们：坏的不确定性可以很坏；《反脆弱》则提醒我们：有些不确定性是好的。

不确定性本身没有绝对好坏，关键看它作用在你的收益函数上是什么形状：

| 类型 | 特征 | 策略 |
|------|------|------|
| 坏的不确定性 | 下行巨大，可能破产、毁灭、不可逆受损 | 管理、隔离、设安全边际 |
| 好的不确定性 | 下行有限，上行很大 | 主动暴露、保留选择权 |
| 反脆弱 | 波动越大越受益 | 制造波动，增加试错 |

文章的行动纲领是：

> 抗拒不确定性不如接受不确定性，接受不确定性不如拥抱不确定性，拥抱不确定性不如制造不确定性。

#### 5.6 不确定性是意义的燃料

这一讲最深的地方，是把不确定性从「风险管理」推进到「意义来源」。

GPT 的洞见是：

> 人类真正喜欢的并不是确定性本身，而是追求确定性的过程带来的精神愉悦与兴奋。

这解释了很多体验：

- 看悬疑剧，如果提前被剧透，乐趣会消失
- 玩解谜游戏，如果直接看答案，体验会下降
- 追连载小说，最吸引人的正是「且听下回分解」
- 学习最爽的瞬间，是从不懂到突然懂了
- 做项目最兴奋的阶段，是问题被一点点解开

我们喜欢的不是静态的确定性，而是动态地把不确定变成确定。

这也和第一条「叙事」呼应：故事之所以有意义，是因为它由一连串「悬念出现 → 行动展开 → 不确定性被解决 → 新的确定性形成」组成。

> 不确定性其实是我们加工意义的燃料。

如果未来完全确定，人生会失去探索、选择、努力、悬念和成长；如果未来完全不可承受，人又会崩溃。好的状态不是没有不确定性，而是有恰到好处的不确定性。

#### 5.7 人生策略：一大块熟悉 + 一小块意外

如果不确定性是燃料，那么燃料太多会吃不消，太少又不够看。理想状态是：

> 一大块熟悉 + 一小块意外。

这不是鼓励鲁莽冒险，而是要求建立稳定底座，同时主动打开新的可能性。

| 稳定底座 | 小块意外 |
|----------|----------|
| 健康、作息、现金流、基本关系、核心能力 | 新项目、新技能、新表达、新合作、新机会 |

这条策略可以转化为几个行动原则：

1. **把坏的不确定性降到可承受范围内**：避免单点失败、保留现金流、建立安全边际。
2. **让自己暴露在好的不确定性中**：学习新技能、做新项目、进入增长网络、积累可迁移能力。
3. **保留选择权**：不要过早把人生锁死在单一路径上。
4. **把焦虑转化为信息问题**：问「我不知道什么」「哪些变量可控」「哪些风险不可逆」「我能增加什么选项」。
5. **主动制造小波动**：在可承受范围内试错，增加遇到正面意外的概率。

#### 5.8 和前四条世界观的关系

前五条世界观可以继续连成一条线：

```
叙事：人需要故事来理解世界并触发行动
  ↓
重尾：真实世界由极端值、乘法和正反馈主导
  ↓
能动：所以要成为主动选择目标函数的 Agent
  ↓
约束：但行动必须尊重硬约束，不能许愿
  ↓
可能：即使尊重约束，世界仍然不可完全预测；要管理、拥抱并制造有利的不确定性
```

「约束」让行动避免许愿，「可能」让行动避免僵化。

如果只讲约束，人容易变得保守：既然边界这么多，那就少动。第五条补上另一面：正因为未来没有被写死，行动才有意义；正因为不确定性存在，世界才会给能动者留下机会。

> 能动性 = 在约束内寻找杠杆，并主动打开新的可能性。

#### 5.9 我的思考与启发

**关于五种不确定性的递进关系**：这五种不确定性不是简单并列的，而是一条「追求确定性的失败路径」。你想通过测量消除不确定性，混沌让测量失效；你想通过计算消除不确定性，计算不可约性让捷径失效；你想退回概率管理，奈特不确定性让概率空间失效；你想让未来剧透，反身性让剧透本身失效。这个递进结构比单纯罗列五个概念更有解释力。

**关于计算不可约性的理解**：它最有启发的地方在于：有些结果不是预先存在于某个公式里，而是在过程中生成的。人生、项目、学习和关系都有类似性质——很多答案不能靠提前想明白，只能通过行动、反馈和迭代生成。

**关于确定性与意义**：人并不是真的想要一个完全确定的人生。完全确定意味着剧透，意味着故事还没开始就已经结束。人真正需要的是可承受的不确定性：既有稳定底座，又有足够的悬念、探索和可能性。

**关于行动策略**：第五条「可能」和第四条「约束」要合起来看。约束告诉我不要许愿，要算账；可能告诉我不要把账算成一条死路，要保留选项，创造正面意外。成熟行动不是消灭不确定性，而是在安全边际内主动接触不确定性。

### 第六条：内核——你的三个「自我」

#### 6.1 这一讲的核心问题

前五条世界观讲的是"世界如何运转"——叙事、重尾、能动、约束、可能。现代人应该了解的世界基本设定也许不可尽数，但最终都会归结到人。我们想了解人，是因为我们渴望成为更好的人。

这一讲的切入点是：**研究 AI 能让我们更深刻地认识自己**，因为人脑本质上也是一个神经网络——如果 AI 的神经网络有某个性质，人脑很可能也有。

把现代学者的理论和古代先贤的看法摊在一起，聊出一个相对简单但特别好用的工作模型——

> 人有三个自我：进程自我、界面自我和内核自我。

文章结尾："有了这些基本认识，我们就可以学习各种思维工具了。"——标志六条基本世界观奠基完成，后面进入具体思维工具。

#### 6.2 进程自我（Process Self）

**定义**：你时时刻刻直观感觉到的那个"我"。

此刻是"我"在阅读，"我"在这里，"手机"在我手里，"我"在思考——进程自我区分了"我"和"非我"，是你在世界上连续存在的主观感觉。

**在哲学家眼中**：这个"我"只是人为创造的方便概念。我是一堆原子，桌子也是一堆原子，为了把这些原子分开叙述，才创造了"我"和"桌子"两个概念。

**本质**：进程自我是大脑维持"这里有个主体"的在线计算，是从输入到输出之间的整条运算链。呼应第一条"叙事"——人的意识来自叙事，进程自我就是你每次叙事时临时出现的角色。

**关键特征：被动**

- 角色的存在感很不稳定（全神贯注打游戏时会忘记"我"）
- 但时刻在运行（心率上升、呼吸变浅、语气变硬 = 进程自我正在呈现"生气"）
- **Libet 实验**：科学家证明在人*意识到*自己的一个决定之前，大脑其实已经做出决定了，中间有几百毫秒延迟

##### Libet 实验详解

本杰明·利贝特（Benjamin Libet），1983 年。检验一个根本问题：**当你说"我决定动手"时，到底是你的意识在发号施令，还是意识只是事后才察觉大脑已经启动了？**

**实验方法**：
- 让被试在"任意想动的时刻"弯曲手腕，同时用脑电图（EEG）记录大脑运动皮层活动
- 被试面前有一个像钟表指针一样旋转的光点；当意识到自己"想要动"的那一瞬间，记住光点所在位置——以此标记主观"决定时刻"（记为 **W**）
- 另外记录大脑"准备电位"（Readiness Potential, **RP**）出现的时刻，和实际动作发生的时刻

**关键发现（时序）**：

| 事件 | 相对于动作的时刻 |
|------|------------------|
| 大脑准备电位 RP 出现 | 动作前约 **550ms** |
| 被试意识到"想要动"（W） | 动作前约 **200ms** |
| 实际动作发生 | **0ms** |

大脑的无意识活动比主观"决定感"早了约 **350ms**。

**结论**：在你"觉得"自己做了决定之前，大脑已经动手了。意识更像事后补记的日志，而不是发号施令的决策者——这正是"进程自我只记录不控制"的实验依据。

**保留与争议**（避免把实验解读过头）：
- Libet 自己并未彻底否定自由意志，他提出"**自由否决（free won't）**"——意识虽不发起动作，却能在最后约 100–200ms 否决无意识的冲动。所以他认为自由意志不在"发起"，而在"能否叫停"
- 2019 年 Schurger 等人提出 RP 可能只是神经活动的随机波动跨越阈值，未必等于"决定已做出"——"大脑提前决定"这个解读仍有讨论空间

但作为世界观级别的论据，Libet 实验的核心启示依然成立：意识到的"我决定"，往往滞后于大脑的实际启动。这条证据支撑了"进程自我是被动角色"的判断，也间接把"真我"从进程自我推向了更深层的内核自我。

> 进程自我只是个新闻发言人而不是实际决策者。它就像是系统运行时的日志（Log），只记录不控制。这就是所谓「五蕴皆空」。

佛学「五蕴」——色、受、想、行、识——大约可以看成进程自我的细分模块：感觉输入、情绪评估、概念加工、意向和行动、觉知。

**常见误区**：你以为"刚才那句话是不是说重了""我为什么又拖延了""我今天有点焦虑"算反思，其实不过是查看运行日志而已，还远没碰到决定长期命运的东西。

#### 6.3 界面自我（Interface Self）

**定义**：你叙事中更稳定、更可控并且能被别人观察和认可的角色。简单说就是你的性格标签、人设、自传和心情叙事。

**与叙事重心的关系**：界面自我很接近哲学家丹尼尔·丹内特（Daniel Dennett）说的「叙事重心（Center of Narrative Gravity）」——大脑里并没有一个小人儿坐在控制室里指挥你的手脚，你想象中那个野心勃勃的自我，只是大脑为了讲通一个故事而虚构出来的主角，是你人生叙事的重心。

**与进程自我的区别**：界面自我是个连续的故事——"我"今天早上起床，"我"去上班，"我"取得重要成果，"我"将会升职加薪。而进程自我是即时的在线计算。

**功能**：让你和别人迅速知道你是谁。朋友圈小作文、面试自我介绍、"我就是这样的人"——这些都是界面自我。

**有因果力**：界面自我可以约束进程自我。你平时内向，但要求自己"今天扮演社牛"，就可以表现得很外向。

**但仍是变量，不是常量**：

| 场景 | 你的界面 |
|------|----------|
| 老板面前 | 唯唯诺诺的下属 |
| 餐厅服务员面前 | 不耐烦的顾客 |
| 回家见孩子 | 慈爱但啰嗦的父亲 |

哪个才是真正的你？似乎都是，其实都不是。现代心理学认为人的性格并不是固定的，会受到具体情境（context）的强烈影响。你扮演的角色，只是不同社交情境下调用的不同"皮肤"或"接口"。

> 界面自我只是你放在前端的用户界面而已。换个应用场景，你的界面马上可以改。

有时候你跟人吵了一架，事后连自己都惊讶："我平时挺温和的啊，怎么会说出那么难听的话？刚才那个人是我吗？"

> 界面自我不是真正的我。

##### 叙事重心详解：物理重心的类比

丹尼尔·丹内特在 1992 年论文 *The Self as a Center of Narrative Gravity* 中提出这个核心类比。

**物理重心**：物体的重心不是一个物质实体——你不能指着某个原子说"重心就在这里"。它不占空间、没有质量。但它是一个真实的、有用的抽象概念：可以精确计算，可以预测物体的行为（推这里才会翻，从这里悬挂才能平衡）。

**叙事重心同理**：当你讲述自己的人生故事——"我出生在XX，我去了XX学校，我创业失败了又爬起来了"——你自然而然需要一个主角和一个讲述者。那个"我"就是叙事重心。它不是你大脑里的某个神经元或脑区，而是叙事本身要求的抽象概念。

三个要点：

1. **叙事重心不是实体**——大脑里没有"一个小人儿在控制室里指挥手脚"
2. **叙事重心是真实且有用的**——就像重心能预测物体行为，叙事重心能整合记忆、指导决策、让你对自己有连贯的理解
3. **叙事重心是叙事产生的**——不是先有"我"再讲故事，而是讲故事的过程中自然产生了"我"。这完全呼应第一条世界观：**"叙事不是因为「我」而存在，「我」是因为叙事而存在"**

##### 笛卡尔剧场：被叙事重心取代的旧模型

"笛卡尔剧场"是丹尼特造的概念，用来命名他要反驳的那个靶子——它不是笛卡尔自己提出的理论。

**笛卡尔其人**：勒内·笛卡尔（René Descartes，1596–1650），法国哲学家兼数学家。哲学上提出"我思故我在"（Cogito, ergo sum），持身心二元论——认为心灵和身体是两种独立实体，心灵通过大脑中的松果体与身体交互。数学上发明了笛卡尔坐标系，将几何问题转化为代数方程，"笛卡尔积"也以他命名。所以笛卡尔剧场和笛卡尔积里的笛卡尔，是同一个人。

**什么是笛卡尔剧场**？人天然有一种直觉：意识就像大脑的某个地方坐着一个"小人儿"（homunculus），所有感官信息像电影一样投射到它面前，由它"观看"后做出决定。这个直觉的哲学根源就是笛卡尔的身心二元论——有一个非物质的"心灵"在接收和加工身体传来的信息。

**丹尼特的批驳**：大脑里根本没有这样一个"最终观众"。神经活动是分布式的、并行的，没有一个中心汇聚点。那个"看东西的我"不是预先存在的观众，而是事后叙事自然产生的叙事重心。所以丹尼特用"叙事重心"取代"笛卡尔剧场"：**自我不是观众，自我是故事的主角**。

##### 丹尼特与万维钢：思想演化线

```
笛卡尔：自我 = 大脑里的实体观众（身心二元论）
  ↓ 丹尼特反驳
丹尼特：自我 = 叙事重心（不是实体，是叙事产生的抽象概念，但真实有用）
  ↓ 万维钢追问
万维钢：叙事重心 = 只是界面自我，背后还有内核自我在生成它
```

丹尼特把"自我"从实体降格为抽象概念，追问的终点是"我们为什么这样叙事"。万维钢同意这个分析，但追问了一步：**谁在选择用哪种方式叙事？谁的先验假设在决定哪些经历被编入故事、哪些被忽略？**

答案是内核自我——生成感知的那套预测参数。所以"真我"不在界面（叙事重心），而在内核（预测参数）。

**这个演化线让界面自我的"被动性"和"因果力"更好理解**：

- **被动性**：界面自我不是自主的——它是内核自我根据情境自动"生成"的角色。你在老板面前谦卑、回家后慈爱，不是在演戏，而是内核在不同情境下直接输出了不同的界面角色
- **因果力**：界面自我"有因果力"（可以约束进程自我）不等于"界面自我能做主"。它更像是内核调用的应用层接口——你可以临时设定"今天扮演社牛"的提示词，但这个提示词本身是内核在某个更高层动机（比如"我想在社交中获得认可"）驱动下写出来的

##### 提示词的边界

界面自我的核心操作工具是**提示词**——你给自己临时设定一个角色、一条叙事重心、一套行为准则。这东西管用，但它的能力边界必须说清楚。

**提示词 = 重新分配已有能力，不是产生新能力**。一个好的提示词能让平庸模型表现得像个专家，就像一个普通人给自己写一句"今天我是冷静的谈判者"，在整个上午的会议里确实能撑住镇定。但这只是**激活**——你调用了权重里已经存在的知识、技能、反应模式，让它们在这次运行里拿到更高的注意力权重。提示词没有往模型里注入任何新参数，所以它不是能力提升。

**那它什么时候会失效？** 四维判据：

| 维度 | 说明 | 举例 |
|------|------|------|
| **难度** | 任务超出权重已有能力时，提示词再好也接不住 | 让没学过法律的人"扮演资深律师"，真到写法律意见书时露馅 |
| **利害** | 利害攸关时，压力会冲垮人设 | 平时"扮演社牛"很自然，真到要当众演讲决定项目去留时手抖 |
| **新颖度** | 遇到训练分布之外的场景，人设没有抓手 | 熟悉的场合扮演"冷面谈判者"很顺，突然进入全新行业立刻退回本能 |
| **时长** | 提示词是浅层杠杆，时间一长就衰减 | 一天的"今天我要果断"撑得住，一周后回到默认模式 |

**退回权重基底**：当压力超过提示词能撑住的阈值——比赛关键时刻掉链子（choking）、危机时退回本能反应（退行）、酒醉疲劳时人设崩塌——这些现象都是同一个机制：**界面自我被冲垮，局面交给内核自我**。模型参数才是基底，提示词只是浅层 buff。

> 你可以靠提示词撑一阵子，但撑不了整个人。稳定改变行为倾向，只有一条路：升级内核——改训练语料、改奖励函数、让网络保持可更新。

这与 6.5 节的类比呼应：LLM 的系统提示词（界面自我）能让模型扮演毒舌投资人，但提示词不会改变权重（内核自我）。人和 AI 的差别不在这里——而在于人能自己选择改什么语料、改什么奖励函数，这是下一节要讲的事。

#### 6.4 内核自我（Core Self）

如果进程自我和界面自我都是被生成的，那到底是谁在背后负责生成呢？也许那才是真正的你——**内核自我（Core Self）**。

**不可被自我感知**：人能感觉到的只有进程自我和界面自我，内核自我是不可被"自我"感知的——因为它就是那个在背后生成感知的东西。

**理论根基：自由能原理 + 预测加工**

- 卡尔·弗里斯顿「自由能原理」：大脑是一台预测机器（第一条已引用）
- 安迪·克拉克（Andy Clark）「预测加工（predictive processing）」：大脑根据过去的经验，对世界构建了一个预测模型。你在环境中跟事物互动，都是先根据预测去观察和行动，然后看结果代表预测正确还是错误；如果预测错误，就修改模型

例子：推开家门，预测灯的开关在右手边，一摸摸空了，于是去左边找——这就是在更新模型。

> 到底是谁在预测呢？就是你的内核自我。

**内核自我是什么**：面前出了个状况，你为什么预测局面会往这个方向而不是那个方向转变？内核自我是一套庞大的、复杂的、甚至是无意识的概率分布和「先验假设（Priors）」——

- 为什么别人听说那个消息觉得是机会，你却觉得是骗局？因为你的先验假设不同
- 为什么有人遇到挫折是战斗或逃跑反应，有人却是习得性无助？因为底层的反应模式不同

**特征**：这些东西不随你今天的心情而变，也不随你在老板还是家人面前而变。内核自我是你的出厂设置加上历史数据的总和，虽然不是绝对的常量，但也是慢变量。它藏得最深，平时不说话，但它决定了你所有的直觉、冲动和潜意识判断。

**与"真我"**：《金刚经》和现代哲学都认为并没有一个单一的、恒定的实体叫"我"。但如果非要找一个最接近"真我"的，那就是内核自我这套算法和参数。

> 你是谁，从根本上，是"你这台机器一般会如何预测世界、如何更新自己"的那套默认代码。内核自我是不容易改、却持续影响你行为倾向的模型参数和更新规则。

> 也许内核自我就是佛学说的「阿赖耶识」，它的成分是「习气」和「业力」。

##### 佛学概念与第六条语言的对应

**阿赖耶识**——佛学"唯识宗"的核心概念，也叫"第八识""藏识"。它像一个超大型仓库，把你过去所有行为、念头、经验的"种子"全部存储下来。它不说话，不显现在意识表���，但它决定了你对世界的默认反应。对应的第六条语言：**内核自我**——存储所有先验参数和预测模式的底层仓库。

**习气（vāsanā）**——字面意思是"熏习之气"。白衣服挂在香炉旁久了，不沾香料却自然带了香味。习气是你长期反复做某类事、接触某类信息之后，在意识深处留下的惯性痕迹。它不是某个具体行为，而是行为背后的默认倾向。对应的第六条语言：你先验的预测模式和默认反应——闻到批评的味道自动防御，看到下跌自动恐慌，这些不是你在"决策"，是习气在做自动推断。

**业力（karma）**——"业"本义是"造作"（行为），业力就是行为产生后果的因果推动力。它不是说"老天在奖罚你"，更像是种地——你种下西瓜种子，阳光雨水来了它长成西瓜，这是因果律，不是道德奖惩。每个行为都在种因，因在条件成熟时结果，果反过来又塑造你。对应的第六条语言：你的奖励函数在持续运作——每个行为都在微调参数，"强化什么，你就会成为什么"。

**三者的闭环**：

```
习气（旧参数）→ 行为 → 业力（奖励函数打分）→ 反馈 → 强化习气
  ↑                                                    ↓
  └─────────────────── 一个闭环 ────────────────────────┘
```

这个闭环解释了为什么内核自我这么难改：习气驱动行为，行为触发业力反馈，反馈进一步固化习气。除非——走第三条路：被现实打脸之后，不逃避（改注意力），不绕过（改行为），而是承认参数错了（改模型）。佛学管这个叫"转识成智"——把阿赖耶识里沉积的业力习气，转化为清醒的觉知和自主的选择。文章里那条西方谚语（思想→语言→行动→习惯→性格→命运）是同一个闭环的另一种表述。

#### 6.5 与 AI 的类比

| | 人 | AI (LLM) |
|--|------|-----------|
| **进程自我** | 当下的念头流 | 大语言模型当前这次运行中的输入、思考、输出（给 ChatGPT 输一句话，它内部层层传播、算注意力、采样 token，最后回复你，这整条流） |
| **界面自我** | 应对情境的面具 | 模型的系统提示词和角色设定（让 ChatGPT 扮演毒舌投资人，它会照办，但这个指令不会改变它自身） |
| **内核自我** | 底层算法和参数 | 模型的结构和参数，即「权重（Weights）」。主流大模型一旦训练好、发布，权重就冻结了，所以这才是模型的真我 |

**核心洞察**：

- 当你在外界刺激下做出反应，改变的只是进程自我
- 当你说"等会儿要见领导，得稳重点"，你是在给界面自我临时写提示词
- 有时候提示词写得好，平庸的模型也能表现得像个专家——但那只是激活，不是能力提升：一旦遇到高压环境，人设就会崩塌，把局面终究交给内核自我

> 绝大多数人在一生的绝大多数时间都只不过是对刺激做出反应和改改提示词而已。

**陷阱**：有时候为了维护人设，你反而会压抑真实过程，让内核自我变得更僵硬——明明可以承认自己不懂，可你非得假装懂，那怎么能更新模型呢？

> 真正的成长必须改写模型参数。

#### 6.6 如何升级内核自我

人比现有 AI 强的地方：我们的参数是活的，可以在生活中持续训练改变。但训练方法跟 AI 差不多，因为毕竟都是神经网络。

你不太可能听完一篇文章就瞬间变成一个新人。参数都是肉长的，得慢慢调。**微调参数的杠杆有两个**：

##### 杠杆一：预训练的语料

语料是你训练的样本，说白了就是你从小到大看听的故事、模仿的行为、加入的群体。

- 短视频训练你对什么上瘾
- 公众号和书训练你对什么敏感
- 你身边的正常人是什么样，训练你的价值观

> 所谓「近朱者赤，近墨者黑」，翻译成现代语言就是信息输入训练神经网络参数。

如果你每天摄入的信息都是情绪化的、碎片的、极端的，你就会变得急躁、浅薄、二极管思维——你的大脑参数被调整成适应那种信息的模式。工程师会说：**你的神经网络过度拟合（overfitting）了垃圾数据**。

##### 杠杆二：强化学习的奖励函数

奖励函数，就是给你的行为提供反馈的那个奖惩机制，说白了就是什么东西在给你做的事情打分。

- 如果奖励函数是"老板看了要夸我"，你就会本能地往报告里塞漂亮话，淡化问题
- 如果奖励函数是"帮团队少踩一个坑"，你就会愿意把难看的数字摊开，把失误写清楚

> 你的伴侣、你的朋友圈、你所在公司的文化都在书写你的奖励函数，要小心选择他们。

**洞见：奖励函数得明确具体才好用**。什么叫"写得好"？什么叫"领导力"？什么叫"健康生活"？泛泛而谈没意义。目标必须具体才可执行：是语文老师说的那种好叫写得好，还是放在网上引发读者热议转发才叫写得好？

> 强化什么，你就会成为什么。

##### 前提：让网络保持可更新状态

在所有那些之前，你要让自己的神经网络处于可更新状态才好。在现实中受挫了，你是直接来一句"这个世界不公平"了事，还是修改自己的模型呢？

自由能原理认为，当一个人面对预测误差（被现实"打脸"）时，有**三个选择**来最小化惊讶：

| 选择 | 难度 | 做法 |
|------|------|------|
| 改注意力 | 最偷懒 | 干脆别看打脸的证据 |
| 改行为 | 稍好 | 以后绕过类似场景 |
| 改模型 | 最难但最值钱 | 承认"原来我是错的"，重写参数 |

> 被现实打脸，本应该是内核自我更新的黄金时机。

#### 6.7 人的终极自由与中西智慧

**人比 AI 高了一层**：人可以自行选择自己的训练样本和奖励函数，而 AI 不可以（就算有一天 AI 想自己选，我们也不会允许，那太危险了）。

> 所以能选择成为一个什么人，可以说是人的终极自由。

这是最根本的「元认知」：你永远都可以抬头看一眼——

> 是谁在训练我？我为什么要往那个方向变？凭什么这个就是好的、那个就是不好的？

**中式智慧**：

- "吾日三省吾身"——随时接受反馈
- "苟日新，日日新，又日新"——持续交付人生的新版本

现在听起来都很有极客精神。

**西方谚语**：

> 当心你的思想，它们会成为语言；
> 当心你的语言，它们会成为行动；
> 当心你的行动，它们会成为习惯；
> 当心你的习惯，它们会成为性格；
> 当心你的性格，它会成为你的命运。

以这一讲的框架来说：思想、语言和行动就是进程自我的在线流动；习惯和性格是你展示出来的界面自我——它们都在默默改写内核自我的参数，凝聚业力。

#### 6.8 和前五条世界观的关系

前六条世界观可以连成一条完整线索：

```
叙事：人需要故事来理解世界并触发行动
  ↓
重尾：真实世界由极端值、乘法和正反馈主导
  ↓
能动：所以要成为主动选择目标函数的 Agent
  ↓
约束：但行动必须尊重硬约束，不能许愿
  ↓
可能：即使尊重约束，世界仍不可完全预测；要管理、拥抱并制造有利的不确定性
  ↓
内核：了解世界最终归结到人；真正的成长不是改情绪和人设，而是改写内核参数
```

第六条是收束篇：前五条讲"世界如何运转"，第六条收束到"人如何运转"。

- **与第一条"叙事"最紧密**：第一条说"自我是叙事重心（丹尼特）"，第六条把这个"自我"拆成三层，"真我"从界面（叙事重心）下沉到内核（预测参数）。自由能原理在两条里都出现——第一条讲"打磨叙事降低自由能"，第六条讲"被打脸时改模型"，是同一原理的两面。
- **与第三条"能动"呼应**：第三条思考里说"做 Agent = 自己选择目标函数"，第六条把它具象为"自行选择训练样本和奖励函数"——这正是人的终极自由。
- **与第四条"约束"呼应**：约束/算账让预测误差暴露，而预测误差暴露正是内核更新的前提。第四条让我们承认硬约束，第六条告诉我们承认后该做什么——改模型而非改注意力。

#### 6.11 我的思考与启发

**关于惯性驱动的进程自我**

在知道"三个自我"之前，回头看自己日常的状态，很大程度上是在进程自我层面惯性滑行——每天输出大量"系统日志"，对这个刺激做反应、对那个任务做输出，忙忙碌碌，但这些都只是被动的运行记录，不是主动的决策。

**关于奖励函数的失效**

进程自我跑得再勤快，如果没有一个明确的奖励函数在给它打分，跑出来的就只是日志，不是成长。以前偶尔也会想想"我到底要什么"，但这种思考像进程自我的一行日志般一闪而过，没有变成界面自我的一部分——没有谱写成一个持续的长远叙事，没有变成每天都在校准方向的那个"人设"。

**关于内核自我的沉睡**

更核心的问题是，内核自我的模型参数——那些先验假设、预测模式、看待世界的基本算法——长期处于"无人维护"状态。不是不想更新，而是根本没意识到它需要更新。偶尔被现实打脸，选择的往往也是第一条路（改注意力：别看打脸的证据）或第二条路（改行为：绕过类似场景），而不是第三条（改模型：承认旧假设错了，重写参数）。"被现实打脸是内核更新的黄金时机"这句话，在学完这讲之后才真正有了重量。

**这个框架带来的转折**

三个自我的分层，最大价值不是让人更了解"自己是什么"，而是让人知道该往哪个方向用力：

- 不是管好每天的念头（进程自我），而是问这些念头的奖励函数是谁写的（界面自我）
- 不是改临时的人设和皮肤（界面自我），而是问谁在选择这个皮肤以及为什么（内核自我）
- 不是反复查看运行日志，而是把日志当成诊断模型的信号——哪些预测偏差反复出现？哪些先验假设该重写了？

"被现实打脸 = 改模型的黄金时机"和"强化什么，你就会成为什么"这两句话，成了学完六条世界观后最想随身携带的行动原则。

**关于"人的终极自由"——看清人与 AI 差别的角度**

> 所以能选择成为一个什么人，可以说是人的终极自由。

这句话读来有种从内心深处腾起的激动。三层自我的框架讲到最后，真正震撼的不是"人有内核自我"这个事实——AI 也有权重作为内核自我——而是**人能自己选择改什么语料、改什么奖励函数**。这一条，AI 做不到（就算有一天 AI 想自己选，我们也不会允许，那太危险了）。

"提示词的边界"告诉我们：人设和提示词都是浅层杠杆，撑不住四维判据（难度/利害/新颖度/时长）的压力测试，高压下必然退回权重基底。人和 AI 在这一点上完全一样——你可以靠提示词撑一阵子，但撑不了整个人。

**但差别出现在下一步**：AI 的权重是被冻结的，发布即定稿；人的参数是活的，可以在生活中持续训练改变。更进一步，人还能"抬头看一眼"——是谁在训练我？我为什么要往那个方向变？凭什么这个是好的、那个是不好的？这是最根本的元认知，AI 没有，也不被允许有。

所以"能选择成为一个什么人"之所以是终极自由，是因为它不只是"我可以选择扮演什么角色"（那是界面自我层面的事，AI 也能做），而是"我可以选择改写自己的内核参数"——选择让什么进入我的训练语料，选择让什么成为我的奖励函数，选择在被现实打脸时走第三条路（改模型）而不是第一条路（改注意力）。

这个自由不是抽象的口号，它有具体的操作面：你今天看了什么、听了什么、跟谁在一起、被什么打分——这些就是你正在选择的"成为什么人"的执行指令。自由不是一次性的选择，而是每一天每一刻的微调方向。
