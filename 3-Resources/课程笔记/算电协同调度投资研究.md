# 算电协同调度 — 投资标的研究报告

## 一、政策背景与确定性

### 核心政策脉络

| 时间 | 政策/事件 | 核心内容 |
|------|----------|----------|
| 2023年 | 发改高技〔2023〕1713号 | 国家算力基础设施行动计划，目标300 EFLOPS、智能算力占比35% |
| 2024年7月 | 发改数据〔2024〕846号 | 数据中心绿色低碳专项行动，推动数据中心参与电网调峰调频 |
| 2024年9月 | 国家数据局征求意见 | 算力与电力协同发展行动计划公开征求意见 |
| 2025年 | 多省地方方案 | 内蒙古、甘肃庆阳（首个试点城市）、贵州、宁夏等出台算电协同实施方案 |

**政策确定性判断**：算电协同从**概念提出 → 顶层设计 → 地方试点**，2025-2026年进入落地实施阶段。虽然具体量化指标（PUE阈值、绿电比例等）仍在演进中，但**方向性确定**——这是发改委、国家数据局、国家能源局三方联合推动的国家战略。

## 二、产业链环节与市场空间

```
算力爆发 → 数据中心用电激增 → 电网调峰压力 → 算电协同调度需求
                                      ↓
                          四大产业链环节：
① 算力调度平台 — 跨区域算力任务智能调度
② 虚拟电厂运营 — 数据中心作为灵活负荷聚合调控
③ IDC节能+微电网 — 数据中心配套储能/液冷/PUE优化
④ 源网荷储一体化 — 新型电力系统整合算力负荷
```

### 市场空间预测

| 年份 | 算电协同相关市场规模 | 发展阶段 |
|------|----------------------|----------|
| 2025 | ~100-200亿元 | 起步期（试点为主） |
| 2026 | ~200-400亿元 | 快速成长期 |
| 2030 | ~500-1000亿元 | 成熟期（全面渗透） |

> 中金公司等券商测算，算电协同是新型电力系统的重要子赛道，2030年市场空间可达500-1000亿元。

## 三、重点投资标的筛选（Top 5）

### 🏆 标的1：国电南瑞（600406）— 电网调度"根系统"提供商

| 维度 | 分析 |
|------|------|
| **核心逻辑** | 国电南瑞是国家电网旗下核心调度系统供应商，掌控电网调度"根系统"。算电协同调度本质上是电网调度系统的延伸和升级，国电南瑞是最核心的基础设施层受益者 |
| **竞争壁垒** | ⭐⭐⭐⭐⭐ 1）国网嫡系，调度系统垄断地位；2）电力调度软件切换成本极高（安全合规+历史数据）；3）技术积累20年+，进入壁垒几乎不可逾越 |
| **算电协同切入点** | 虚拟电厂平台核心供应商 + 参与国网算电协同调度试点 + 新一代调度系统（支持算力负荷柔性调度） |
| **商业模式** | 项目交付+SaaS运维费，毛利率高且稳定 |
| **风险点** | 增长节奏受国网投资周期影响；算电协同业务占比尚小 |

**估值逻辑**：作为电网数字化"基础设施"，类似"电力版的操作系统"。确定性最高，弹性略低。

---

### 🏆 标的2：国能日新（300162）— 新能源功率预测→虚拟电厂→算电协同的升维路径

| 维度 | 分析 |
|------|------|
| **核心逻辑** | 新能源功率预测龙头，正在从"卖软件"向"卖服务+运营分成"转型。算电协同需要精准预测新能源出力（决定算力可调度窗口），国能日新的预测能力是算电协同算法的核心输入 |
| **竞争壁垒** | ⭐⭐⭐⭐ 1）功率预测市占率领先；2）数据积累+算法迭代形成飞轮效应；3）客户粘性高（预测精度直接关系风电/光伏场站收益） |
| **算电协同切入点** | 功率预测→虚拟电厂聚合→算力负荷与绿电供给匹配优化，形成"预测+调度+交易"闭环 |
| **商业模式升级** | 从软件许可/SaaS → 虚拟电厂运营分成 → 电力交易服务费，利润空间打开 |
| **风险点** | 虚拟电厂运营分成模式尚在验证期；市值相对较小 |

**估值逻辑**：商业模式从"卖铲子"升级到"挖金矿分成"，利润弹性最大。如果虚拟电厂运营分成模式成功验证，估值重构空间显著。

---

### 🏆 标的3：科华数据（002335）— 数据中心+储能+微电网"三合一"

| 维度 | 分析 |
|------|------|
| **核心逻辑** | 国内少数同时深耕数据中心运营、储能系统、微电网三大业务的公司。算电协同需要数据中心侧具备储能+微电网能力（才有灵活性参与电网调度），科华数据的"三合一"布局天然契合 |
| **竞争壁垒** | ⭐⭐⭐⭐ 1）数据中心+储能+微电网三业务协同，竞争对手单一维度；2）数据中心客户资源可直接转化为算电协同试点场景；3）储能技术积累（液冷储能系统等）提供硬件壁垒 |
| **算电协同切入点** | IDC配套储能/微电网 → 数据中心柔性负荷能力 → 参与虚拟电厂调峰获得收益 |
| **商业模式** | 硬件销售+系统集成+运营服务，从"卖设备"向"卖解决方案"升级 |
| **风险点** | 三业务协同尚未完全兑现；利润率受硬件竞争挤压 |

**估值逻辑**：如果三业务真正实现协同，从"三个独立业务"变成"一个闭环解决方案"，估值乘数提升。

---

### 🏆 标的4：中科曙光（603019）— 算力侧调度"操作系统"

| 维度 | 分析 |
|------|------|
| **核心逻辑** | 国产高性能计算领军企业，推出统一算力调度平台。算电协同需要"算力侧调度系统"与"电力侧调度系统"对接，中科曙光是算力侧的天然入口 |
| **竞争壁垒** | ⭐⭐⭐⭐ 1）国产HPC/智算中心技术积累深厚；2）算力调度平台跨区域管理能力；3）中科院体系背景，政策资源优势 |
| **算电协同切入点** | 算力调度平台 → "算随电动"（算力任务随绿电供给迁移）→ 绿色算力溢价+调度服务费 |
| **商业模式** | 从硬件销售向"基础设施+算力运营+调度服务"转型，服务收入占比提升 |
| **风险点** | 受美国制裁影响（实体清单）；传统硬件业务占比仍高，转型节奏不确定 |

**估值逻辑**：如果算力调度平台成功商业化，从"卖服务器"变成"卖算力服务"，估值逻辑重构。但制裁风险需持续跟踪。

---

### 🏆 标的5：远光软件（002063）— 国网体系内的算电协同解决方案商

| 维度 | 分析 |
|------|------|
| **核心逻辑** | 深耕电力行业20年+，是国内少数同时具备电力行业深度理解和AI/算力技术能力的软件企业。在国家电网体系内提供调度自动化、电力市场交易、碳资产管理等核心系统 |
| **竞争壁垒** | ⭐⭐⭐⭐ 1）国网体系内长期合作关系；2）电力业务理解深度不可替代；3）调度+交易+碳管理多业务线协同 |
| **算电协同切入点** | 电力调度系统升级 → 算力与电力联合优化算法 → 算电协同解决方案 |
| **商业模式** | 软件许可+SaaS+项目实施，毛利率较高 |
| **风险点** | 对国网依赖度高；市值较小，市场关注度低 |

**估值逻辑**："小而专"的电力软件公司，如果算电协同业务成为独立增长曲线，估值弹性较大。

## 四、投资策略建议

### 确定性 vs 弹性矩阵

| | 高确定性 | 高弹性 |
|---|---------|--------|
| **优先配置** | 国电南瑞 — 调度"根系统"，确定性最强 | 国能日新 — 商业模式升维，利润弹性最大 |
| **均衡配置** | 科华数据 — 三业务协同，中期弹性 | 中科曙光 — 算力侧入口，但制裁风险 |
| **观察配置** | 远光软件 — 小而专，待催化 | |

### 配置建议

- **核心仓位（60%）**：国电南瑞 + 国能日新，确定性+弹性的最佳组合
- **进攻仓位（30%）**：科华数据 + 中科曙光，等待业务协同兑现和商业模式验证
- **观察仓位（10%）**：远光软件，跟踪算电协同业务独立披露信号

### 关键催化节点

| 时间 | 催化事件 |
|------|----------|
| 2025年H2 | 虚拟电厂参与数据中心调峰商业模式验证结果 |
| 2025年Q3-Q4 | 国电南瑞/国能日新半年报/三季报中算电协同相关业务披露 |
| 2026年 | 算力调度国家标准出台，行业从试点走向规模化 |
| 2026年 | 更多省份出台算力-电力联合规划政策 |

## 五、风险提示

1. **试点推进节奏不及预期**：算电协同目前以试点为主，规模化时间线不确定
2. **商业模式尚在验证期**：虚拟电厂调峰补偿、算力调度服务费等变现路径需要实际数据验证
3. **政策细节仍在演进**：具体量化指标（PUE、绿电比例等）尚未完全定量化落地
4. **部分标的估值已较高**：中科曙光、国能日新等已有一定市场关注度
5. **技术路线不确定性**：算电协同调度涉及跨行业协同，技术标准尚未统一
